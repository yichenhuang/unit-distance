Round 1

User

Theorem. There exist an absolute constant $\delta > 0$ and an infinite sequence $\{P_i\}$ of finite point sets in $\mathbb{R}^2$ such that $|P_i| \to \infty$ and $u(P_i) \ge |P_i|^{1+\delta}$ for all $i$, where $u(P_i) = \frac{1}{2} | \{ (p,q) \in P_i \times P_i : \|p-q\|_2 = 1 \} |$ is the number of unit-distance pairs.

Remark. This result disproves the Erdős Unit Distance Conjecture.

As a first step, brainstorm and propose three most promising approaches to prove this theorem. Explore each approach to sufficient depth, and then rank them from most to least promising.

Assistant

A useful organizing principle is the following.

If \(U\subset S^1\) is a set of unit vectors and \(A\subset \mathbb R^2\) is a finite set such that, for many \(u\in U\), many translates \(a+u\) also lie in the final point set \(P\), then

\[ u(P)\ \ge\ \frac12\sum_{u\in U} |\{a\in P:a+u\in P\}|. \]

So a very promising route is:

Build a finite “Følner-type” set \(P\) that is almost invariant under \(M\) distinct unit translations, with \(M\ge |P|^\delta\).

The classical lattice construction does exactly this with \(P\) a large square grid and \(U\) the set of lattice vectors of a fixed length, but the number of such \(U\)’s is only \(n^{o(1)}\). The new proof should somehow produce polynomially many unit translations relative to the size of the finite ambient set.

Below are three approaches I would regard as most promising.

1. Arithmetic amplification via norm-one elements in high-degree number fields

Core idea

Replace the ordinary integer lattice \(\mathbb Z^2\) by an additive box inside a high-degree totally real number field \(F\), and use many algebraic solutions of

\[ x^2+y^2=1,\qquad x,y\in F, \]

as unit translations. Then embed \(F\) into \(\mathbb R\) using one chosen real embedding \(\sigma:F\hookrightarrow \mathbb R\). If \(x^2+y^2=1\) in \(F\), then

\[ \sigma(x)^2+\sigma(y)^2=1, \]

so \((\sigma(x),\sigma(y))\) is an honest Euclidean unit vector in \(\mathbb R^2\).

The amplification comes from taking \([F:\mathbb Q]=d\to\infty\). A fixed rational prime \(p\) can split completely in \(F\), producing \(d\) independent local choices. Those local choices can yield exponentially many algebraic norm-one elements, while additive boxes in \(F\) also have only exponential size in \(d\). This gives a fixed power gain.

This is the approach I would rank as most promising.

More detailed plan

Fix a rational prime

\[ p\equiv 1 \pmod 4, \]

say \(p=5\), so that \(p\) splits in \(\mathbb Q(i)\). We seek an infinite sequence of totally real fields \(F_i\) with degrees

\[ d_i=[F_i:\mathbb Q]\to\infty \]

such that:

  1. \(p\) splits completely in \(F_i\);
  2. the root discriminants \(\operatorname{Disc}(F_i)^{1/d_i}\) are uniformly bounded;
  3. the corresponding relative norm-one torus over \(F_i\) has exponentially many controlled \(S\)-integral points.

The bounded root discriminant condition is important because it lets us count additive boxes in \(F_i\) uniformly exponentially in \(d_i\). Infinite totally real class field towers, obtained through Golod–Shafarevich/Martinet-type constructions, are the natural source of such fields.

Let

\[ E_i = F_i(i). \]

Let \(\overline{\phantom z}\) denote complex conjugation in \(E_i/F_i\). For \(z\in E_i\), write

\[ z=x+iy,\qquad x,y\in F_i. \]

Then

\[ z\overline z = x^2+y^2. \]

Thus elements \(z\in E_i\) satisfying

\[ z\overline z=1 \]

produce algebraic unit vectors \((x,y)\in F_i^2\).

Because \(p\) splits completely in \(F_i\), and also splits in \(F_i(i)/F_i\), the primes above \(p\) in \(F_i\) split into conjugate pairs in \(E_i\). At the level of \(S\)-units, the relative norm-one group

\[ \mathcal T_i = \{z\in \mathcal O_{E_i}[1/p]^\times : z\overline z=1\} \]

has rank roughly \(d_i\). More concretely, the valuation data at the conjugate prime pairs above \(p\) gives \(d_i\) independent directions. Therefore, for a fixed integer \(L\), one expects many elements \(z\in \mathcal T_i\) whose \(p\)-adic valuations are bounded by \(L\). In an idealized principal-splitting situation, one would get about

\[ (2L+1)^{d_i} \]

such elements: for each of the \(d_i\) split prime pairs, choose an exponent in \(\{-L,-L+1,\dots,L\}\).

Thus we hope to prove an arithmetic lemma of the following shape.

Key arithmetic lemma to aim for

There exist fixed constants \(L\ge 1\) and \(C>1\), and infinitely many totally real fields \(F_i\) of degrees \(d_i\to\infty\), such that for each \(i\) there is a set

\[ V_i\subset (p^{-L}\mathcal O_{F_i})^2 \]

with

\[ |V_i|\ge C^{d_i} \]

and

\[ x^2+y^2=1 \]

for every \((x,y)\in V_i\).

Equivalently, \(V_i\) is an exponentially large set of algebraic unit vectors whose denominators are supported only at the fixed prime \(p\), with bounded \(p\)-adic depth \(L\).

This lemma is the arithmetic heart of the construction. It can be attacked through the relative norm-one torus

\[ \operatorname{Res}^{1}_{E_i/F_i}\mathbb G_m \]

and the \(S\)-unit exact sequence. Class group obstructions can be handled either by arranging principalization in the tower or by working with a finite-index sublattice of the valuation lattice; since only an exponential lower bound \(C^{d_i}\) with \(C>1\) is needed, a bounded-loss version suffices.

Constructing the point set from the arithmetic lemma

Fix one real embedding

\[ \sigma_i:F_i\hookrightarrow \mathbb R. \]

For a large constant \(R>1\), define an additive box

\[ B_i(R) = \left\{ a\in p^{-L}\mathcal O_{F_i} : |\tau(a)|\le R \text{ for every real embedding } \tau:F_i\hookrightarrow \mathbb R \right\}. \]

Then define

\[ P_i = \left\{ (\sigma_i(a),\sigma_i(b)) : a,b\in B_i(R) \right\} \subset \mathbb R^2. \]

Because \(\sigma_i\) is injective on \(F_i\), the map

\[ (a,b)\mapsto (\sigma_i(a),\sigma_i(b)) \]

is injective, so

\[ |P_i|=|B_i(R)|^2. \]

Size estimate for \(P_i\)

Under the full Minkowski embedding

\[ F_i\hookrightarrow \mathbb R^{d_i}, \]

the lattice \(p^{-L}\mathcal O_{F_i}\) has covolume roughly

\[ p^{-Ld_i}\sqrt{\operatorname{Disc}(F_i)}. \]

The box \(|\tau(a)|\le R\) for all \(\tau\) has volume \((2R)^{d_i}\). Since the root discriminants are bounded, geometry-of-numbers estimates should give constants \(A_-,A_+>1\), depending only on \(p,L,R\), such that

\[ A_-^{d_i} \le |B_i(R)| \le A_+^{d_i}. \]

Hence

\[ |P_i| = |B_i(R)|^2 \le A_+^{2d_i}. \]

In particular \(|P_i|\to\infty\).

Counting unit distances

Take \((x,y)\in V_i\). Since

\[ x^2+y^2=1 \]

in \(F_i\), for every real embedding \(\tau\),

\[ \tau(x)^2+\tau(y)^2=1. \]

Therefore

\[ |\tau(x)|\le 1,\qquad |\tau(y)|\le 1. \]

Define an interior box

\[ B_i^\circ(R) = \left\{ a\in p^{-L}\mathcal O_{F_i} : |\tau(a)|\le R-1 \text{ for every real embedding } \tau \right\}. \]

Then for every \(a,b\in B_i^\circ(R)\) and every \((x,y)\in V_i\), we have

\[ a+x,\ b+y\in B_i(R). \]

Thus the two points

\[ (\sigma_i(a),\sigma_i(b)) \]

and

\[ (\sigma_i(a+x),\sigma_i(b+y)) \]

both lie in \(P_i\), and their Euclidean distance is

\[ \sqrt{ \sigma_i(x)^2+\sigma_i(y)^2 } = 1. \]

Therefore each algebraic unit vector \((x,y)\in V_i\) gives approximately \(|B_i^\circ(R)|^2\) unit-distance pairs.

If

\[ |B_i^\circ(R)|\ge \eta^{d_i}|B_i(R)| \]

for some \(\eta>0\), then

\[ u(P_i) \ge \frac12 |V_i|\cdot |B_i^\circ(R)|^2 \ge \frac12 C^{d_i}\eta^{2d_i}|B_i(R)|^2. \]

Since \(|P_i|=|B_i(R)|^2\), this becomes

\[ u(P_i) \ge \frac12 (C\eta^2)^{d_i}|P_i|. \]

Choose \(R\) large enough so that \(\eta\) is close to \(1\), and ensure \(C\eta^2>1\). Since

\[ |P_i|\le A_+^{2d_i}, \]

we get

\[ (C\eta^2)^{d_i} \ge |P_i|^\delta \]

with

\[ \delta = \frac{\log(C\eta^2)}{2\log A_+} >0. \]

Hence

\[ u(P_i)\ge |P_i|^{1+\delta} \]

for all \(i\).

Why this approach is promising

This approach gives a clean conceptual mechanism:

  • the point set size grows like \(A^{d}\);
  • the number of unit translations grows like \(C^{d}\);
  • choosing \(C>1\) gives a fixed exponent gain.

It also explains why the usual lattice construction falls short. In \(\mathbb Z[i]\), the number of divisors of an integer is only \(R^{o(1)}\). But in a high-degree field where a fixed prime splits into \(d\) pieces, the number of controlled norm-one choices can be exponential in \(d\), while the additive ambient box is also only exponential in \(d\). That is precisely the polynomial amplification needed.

The main technical tasks are arithmetic rather than geometric:

  1. construct a tower \(F_i\) with \(p\) split completely and bounded root discriminant;
  2. prove a uniform exponential lower bound for controlled relative norm-one \(S\)-units;
  3. establish uniform lattice-counting estimates for the adelic boxes \(B_i(R)\).

Once those are in place, the Euclidean unit-distance construction is straightforward.

2. Finite-field unit-distance graphs lifted through split primes

Core idea

Over a finite field \(\mathbb F_q\), the unit-distance graph on \(\mathbb F_q^2\) is dense. Indeed,

\[ |\{(x,y)\in \mathbb F_q^2:x^2+y^2=1\}| = q+O(1), \]

so every point has about \(q\) unit neighbors, and the graph has about \(q^3\) directed unit edges on \(q^2\) vertices.

This suggests trying to imitate the finite-field graph inside a real construction by using a number field \(F\) in which a fixed prime \(p\) splits completely:

\[ \mathcal O_F/p\mathcal O_F \cong \mathbb F_p^{d}, \qquad d=[F:\mathbb Q]. \]

Then the reduction of the unit circle modulo \(p\) is

\[ C(\mathcal O_F/p\mathcal O_F) \cong C(\mathbb F_p)^d, \]

which has roughly

\[ (p+O(1))^d \]

unit directions. If one can lift a positive exponential fraction of these residue directions to genuine algebraic solutions of

\[ x^2+y^2=1 \]

with controlled denominators, then the same Følner-box construction from Approach 1 gives many real Euclidean unit distances.

How the lift would work

Let

\[ C:x^2+y^2=1 \]

be the unit circle over \(F\). Because \(p\equiv 1\pmod 4\), the conic \(C\) is split modulo \(p\), and

\[ |C(\mathbb F_p)|=p-1 \]

if \(p\equiv 1\pmod 4\). Therefore

\[ |C(\mathcal O_F/p\mathcal O_F)| = (p-1)^d. \]

The desired lifting statement is something like:

For infinitely many totally real \(F\) of degree \(d\), a set of at least \(\beta^d\) residue classes in \(C(\mathcal O_F/p\mathcal O_F)\), with \(\beta>1\), lifts to exact points

\[ (x,y)\in C(F) \]

lying inside a fixed controlled denominator module \(p^{-L}\mathcal O_F^2\).

If such a lifting lemma holds, then we again define

\[ B_i(R) = \{a\in p^{-L}\mathcal O_{F_i}:|\tau(a)|\le R \text{ for all }\tau\}, \]

and

\[ P_i = \{(\sigma_i(a),\sigma_i(b)):a,b\in B_i(R)\}. \]

Every lifted unit vector \((x,y)\) translates a large interior portion of \(P_i\) to another part of \(P_i\), yielding unit distances.

Relation to strong approximation

The unit circle \(C\) is rational. Over a field of characteristic not \(2\), one has the parametrization

\[ x=\frac{1-t^2}{1+t^2}, \qquad y=\frac{2t}{1+t^2}. \]

So one possible route is:

  1. choose local parameters \(t_{\mathfrak p}\in \mathbb F_p\) independently at the \(d\) primes \(\mathfrak p\mid p\);
  2. use CRT/weak approximation to choose \(t\in F\) matching those residues;
  3. ensure that \(1+t^2\) has only controlled denominators, ideally supported at a fixed finite set of primes;
  4. obtain exact global points \((x,y)\in C(F)\).

Equivalently, after adjoining \(i\), the circle becomes a norm-one torus. The lifting problem becomes a controlled \(S\)-unit approximation problem on

\[ \operatorname{Res}^{1}_{F(i)/F}\mathbb G_m. \]

This is closely related to Approach 1, but the finite-field viewpoint gives a clearer combinatorial target: lift as much as possible of the finite-field unit graph.

Expected parameter count

Suppose we can lift

\[ M_i\ge \beta^{d_i} \]

unit directions, with \(\beta>1\), into a denominator module \(p^{-L}\mathcal O_{F_i}^2\), where \(L\) is fixed. The additive box has size

\[ |P_i| \le A^{d_i} \]

for some fixed \(A\). Then the same translation argument gives

\[ u(P_i) \ge |P_i|\cdot \beta_0^{d_i} \]

for some \(\beta_0>1\), after boundary losses. Hence

\[ u(P_i) \ge |P_i|^{1+\delta}, \qquad \delta = \frac{\log \beta_0}{\log A}. \]

The value of \(\delta\) would depend on how efficient the lifting is and how large \(L\) must be.

Why this approach is promising

This approach has a very appealing guiding model: the dense finite-field unit-distance graph. The real construction would be an exact algebraic lift of a finite-field Cayley graph.

It also suggests possible improvements over the simpler divisor/S-unit method in Approach 1. The divisor method may give something like \((2L+1)^d\) directions. A full finite-field lift could in principle give roughly \(p^d\) directions. Of course the Szemerédi–Trotter upper bound in the real plane prevents an overly efficient lift from producing \(n^{3/2}\) unit distances, so some volume loss is inevitable. But even a modest exponential lift is enough for a fixed \(\delta>0\).

The main difficulty is denominator control. Weak approximation alone gives exact global points, but their denominators may involve many primes and become too expensive. The challenge is to combine approximation with \(S\)-integrality or controlled norm-one \(S\)-units.

I would rank this second: it is conceptually powerful and may yield stronger parameters, but it has more moving parts than the norm-one \(S\)-unit construction.

3. Direct Euclidean incidence construction from low-complexity arcs of the circle

Core idea

Try to build the desired point set directly in \(\mathbb R^2\) by exploiting the local form of the unit circle near a tangency point. This reframes the problem as an incidence construction involving translates of a fixed analytic curve.

Place one cluster of points near the origin and another near \((1,0)\). Let

\[ \phi(t)=\sqrt{1-t^2}-1. \]

Then

\[ (1+\phi(t),t) = (\sqrt{1-t^2},t) \]

has Euclidean length \(1\). Therefore, for any real numbers \(a,b,t\), the two points

\[ (a,b) \]

and

\[ (1+a+\phi(t),\, b+t) \]

are at distance exactly \(1\).

Thus, if we choose finite sets \(A,B,T\subset\mathbb R\), define

\[ P_0=A\times B \]

and

\[ P_1= \bigl(1+(A+\phi(T))\bigr)\times (B+T), \]

then for every \(a\in A\), \(b\in B\), and \(t\in T\), the point

\[ (a,b)\in P_0 \]

is at unit distance from

\[ (1+a+\phi(t), b+t)\in P_1. \]

Therefore

\[ u(P_0\cup P_1) \ge |A||B||T|. \]

The total number of points is bounded by

\[ |P_0\cup P_1| \le |A||B|+ |A+\phi(T)|\,|B+T|. \]

So the goal becomes:

Find \(T\) such that both \(T\) and \(\phi(T)\) have small additive complexity.

The ideal Elekes-type parameter choice

For the parabola \(\phi(t)=-t^2\), one can take \(T=\{1,\dots,k\}\), because \(T^2\) lies in an ordinary one-dimensional arithmetic progression of length \(O(k^2)\). This is the classical Elekes incidence mechanism.

For the circle, suppose we could find sets satisfying

\[ |T|=k,\qquad |B|=k,\qquad |B+T|=O(k), \]

and also choose \(A\) with

\[ |A|=k^2, \qquad |A+\phi(T)|=O(k^2). \]

Then

\[ |P_0| = |A||B| = k^3, \]

and

\[ |P_1| = O(k^2)\cdot O(k) = O(k^3). \]

So

\[ |P_0\cup P_1|=O(k^3). \]

Meanwhile, the number of unit distances is at least

\[ |A||B||T| = k^2\cdot k\cdot k = k^4. \]

Thus this would give

\[ u(P) \gg |P|^{4/3}, \]

which is essentially the maximum exponent allowed by the Szemerédi–Trotter upper bound.

Even a weaker version, with

\[ |A+\phi(T)|\le k^{2+\varepsilon} \]

and

\[ |B+T|\le k^{1+\varepsilon}, \]

for some fixed \(\varepsilon<1/3\), would already give a fixed exponent gain.

Where such \(T\) might come from

For a generic real set \(T\), the set \(\phi(T)\) will not have small additive structure. Thus the hard part is to find many points on the unit circle whose two coordinate projections simultaneously lie in low-complexity additive sets.

This is exactly where arithmetic enters.

One could try to produce \(T\) from algebraic unit vectors. Namely, suppose we have many algebraic solutions

\[ x^2+y^2=1 \]

with both \(x\) and \(y\) lying in a small additive progression inside a high-degree field. Under one embedding \(F\hookrightarrow\mathbb R\), the \(y\)-coordinates give \(T\), and the \(x-1\) coordinates give \(\phi(T)\). The adelic-box machinery from Approach 1 is precisely a way to manufacture such low-complexity coordinate sets.

A more analytic variant would be to use the Taylor expansion

\[ \phi(t) = -\frac{t^2}{2} -\frac{t^4}{8} -\frac{t^6}{16} -\cdots \]

and choose \(t\)’s lying in a structured algebraic progression where the higher powers remain controlled. One could attempt to model the construction first over a truncated polynomial ring, where the series becomes finite, and then specialize to real algebraic numbers using an implicit-function or Hensel-type lifting argument. This would be a more directly Euclidean proof.

Why this approach is promising

This approach has several advantages:

  1. It works directly in the Euclidean plane.
  2. It naturally produces bipartite unit distances between two clusters.
  3. It reduces the problem to a concrete additive-combinatorial target: find \(T\) with both \(T\) and \(\phi(T)\) additively structured.
  4. In the ideal case, it gives the optimal \(n^{4/3}\) exponent.

However, the exactness requirement is severe. Approximate parabolic behavior is not enough; the distances must be exactly \(1\). Therefore the construction likely still needs a serious arithmetic input, such as the high-degree norm-one machinery from Approach 1.

I would rank this third: it is geometrically elegant and useful as a template, but the crucial low-complexity circle-arc construction is the hard part.

Ranking

1. Norm-one \(S\)-unit / high-degree number-field construction

Most promising.

This gives the cleanest route to a proof. It supplies exponentially many exact unit directions from algebraic norm-one elements, and additive boxes in the same field have only exponential size. The exponent calculation is straightforward:

\[ |P_i|\le A^{d_i}, \qquad \text{number of unit directions}\ge C^{d_i}, \]

so

\[ u(P_i)\ge |P_i|^{1+\delta} \]

with

\[ \delta=\frac{\log C}{\log A}>0 \]

after boundary losses.

The main ingredients are standard-looking arithmetic tools: class-field towers, splitting of a fixed prime, relative norm-one \(S\)-units, and geometry-of-numbers estimates.

2. Finite-field unit graph lifted through split primes

Second most promising.

This approach starts from the dense unit-distance graph over \(\mathbb F_p^2\), then uses a totally split prime in a high-degree number field to imitate a product of finite-field graphs. It could potentially produce stronger constants than the divisor/S-unit method.

Its main difficulty is controlling denominators when lifting residue-class unit vectors to exact algebraic unit vectors. Strong approximation gives flexibility, but exact \(S\)-integrality is the key obstruction to manage.

3. Direct Euclidean incidence construction from structured circle arcs

Third most promising.

This approach gives a very transparent geometric mechanism. If one can find \(T\) with both \(T\) and \(\sqrt{1-T^2}\) additively structured, then a two-cluster construction yields many unit distances, potentially as many as \(n^{4/3}\).

The downside is that constructing such \(T\) exactly is difficult. In practice, the required structured arc of the circle likely comes from the same arithmetic source as Approach 1. Still, this approach is valuable because it translates the problem into a concrete additive-combinatorial form and may lead to a cleaner final presentation once the arithmetic input is established.

Assistant

Below is a complete development of the top-ranked number-field/\(S\)-unit approach.

I will be explicit about the two main technical adaptations needed to make the brainstormed strategy rigorous:

  1. Principal-prime issue. We cannot assume the primes over \(p\) are principal. Instead, we use a class-group pigeonhole argument. Among many exponent vectors, many represent the same ideal class; differences then give principal fractional ideals, which produce norm-one elements.

  2. Skew lattice issue. A centered Minkowski box in \(\mathcal O_F\) need not contain the “expected” number of lattice points if the lattice is skew. Instead, we use translated boxes. Averaging over a fundamental parallelepiped gives a translate with many interior lattice points, while a simple algebraic packing bound gives a uniform exponential upper bound.

The only external arithmetic input is a standard \(T\)-split class-field-tower theorem coming from Golod–Shafarevich theory.

1. Arithmetic input: a totally real split tower

We use the following standard theorem.

Lemma 1: \(T\)-split bounded-root-discriminant tower

There exist a rational prime \(p\equiv 1 \pmod 4\), a constant \(\Delta < \infty\), and an infinite sequence of totally real number fields

\[ F_1,F_2,F_3,\dots \]

such that, writing

\[ d_i=[F_i:\mathbb Q], \]

we have:

  1. \(d_i\to\infty\);
  2. \(p\) splits completely in \(F_i\);

  3. the root discriminants satisfy

    \[ \operatorname{rd}(F_i) = |\operatorname{Disc}(F_i)|^{1/d_i} \le \Delta \]

    for all \(i\).

Explanation of the input

This is a standard consequence of the \(T\)-split Hilbert class-field tower theorem of Golod–Shafarevich/Hajir–Maire. Applied to \(k=\mathbb Q\), to the finite prime \(p=5\), and to the real place, it gives a totally real field \(F_0\) in which \(5\) splits completely and whose maximal everywhere-finite-unramified extension, with all primes above \(5\) and all real places split completely, is infinite. Taking finite subfields \(F_i\) of this infinite extension gives the desired sequence. Since the tower is unramified at all finite primes over \(F_0\), all root discriminants are equal to \(\operatorname{rd}(F_0)\). Since real places split completely, all fields in the tower remain totally real.

For the rest of the proof, fix such a prime \(p\equiv 1\pmod 4\), such a sequence \(F_i\), and such a root-discriminant bound \(\Delta\).

2. A uniform class-number bound

For each \(i\), put

\[ K_i = F_i(\iota), \qquad \iota^2=-1. \]

Let \(c\) denote the nontrivial automorphism of \(K_i/F_i\), so \(c(\iota)=-\iota\).

Since \(F_i\) is totally real, \(\iota\notin F_i\), and therefore

\[ [K_i:\mathbb Q]=2d_i. \]

We need a uniform exponential upper bound for the class numbers \(h(K_i)\).

Lemma 2: exponential class-number bound

There is a constant \(H<\infty\), depending only on the tower, such that

\[ h(K_i)\le H^{d_i} \]

for all \(i\).

Proof

First we bound the root discriminants of \(K_i\). The relative discriminant of \(F_i(\iota)/F_i\) divides \(4\mathcal O_{F_i}\), because \(F_i(\iota)\) is generated by a root of \(X^2+1\), whose discriminant is \(-4\). Hence

\[ |\operatorname{Disc}(K_i)| \le |\operatorname{Disc}(F_i)|^2 \cdot 4^{d_i}. \]

Taking \(1/(2d_i)\)-th powers gives

\[ \operatorname{rd}(K_i) \le 2\,\operatorname{rd}(F_i) \le 2\Delta. \]

Now let \(K\) be any number field of degree \(n\) with \(\operatorname{rd}(K)\le \rho\). We claim that \(h(K)\le C(\rho)^n\) for some constant \(C(\rho)\).

By Minkowski’s bound, every ideal class of \(K\) contains an integral ideal of norm at most

\[ M_K \le \left(\frac{4}{\pi}\right)^{r_2} \frac{n!}{n^n} |\operatorname{Disc}(K)|^{1/2} \le \left(\left(\frac4\pi\right)^{1/2}\rho^{1/2}\right)^n. \]

Let

\[ B(\rho)=\left(\frac4\pi\right)^{1/2}\rho^{1/2}. \]

The number of integral ideals of norm at most \(M_K\) is at most

\[ M_K^2 \zeta_K(2). \]

Indeed, since \(1\le (M_K/N\mathfrak a)^2\) whenever \(N\mathfrak a\le M_K\),

\[ \#\{\mathfrak a : N\mathfrak a\le M_K\} \le M_K^2 \sum_{\mathfrak a} \frac1{(N\mathfrak a)^2} = M_K^2\zeta_K(2). \]

Also,

\[ \zeta_K(2)\le \zeta(2)^n. \]

This follows Euler factor by Euler factor: over a rational prime \(\ell\), there are at most \(n\) prime ideals of \(K\), and each has norm at least \(\ell\).

Therefore

\[ h(K) \le B(\rho)^{2n}\zeta(2)^n = \bigl(B(\rho)^2\zeta(2)\bigr)^n. \]

Applying this with \(\rho=2\Delta\) and \(n=2d_i\), we get

\[ h(K_i) \le \bigl(B(2\Delta)^2\zeta(2)\bigr)^{2d_i}. \]

Thus there is a constant \(H\) such that

\[ h(K_i)\le H^{d_i}. \]

This proves the lemma. \(\square\)

3. Many algebraic unit vectors

We now show that every \(F_i\) supplies exponentially many algebraic solutions of

\[ x^2+y^2=1 \]

with uniformly bounded denominators.

Lemma 3: many controlled norm-one vectors

Fix \(L\ge 1\). For each \(i\), there is a set

\[ V_i\subseteq \bigl((2p^L)^{-1}\mathcal O_{F_i}\bigr)^2 \]

such that:

  1. every \((x,y)\in V_i\) satisfies

    \[ x^2+y^2=1; \]
  2. the elements of \(V_i\) are distinct;

  3. one has the lower bound

    \[ |V_i| \ge \frac{(L+1)^{d_i}}{h(K_i)}. \]

Proof

Fix \(i\), and write \(F=F_i\), \(K=K_i=F(\iota)\), \(d=d_i\).

Because \(p\) splits completely in \(F\),

\[ p\mathcal O_F = \mathfrak p_1\cdots \mathfrak p_d, \]

with all \(\mathfrak p_j\) distinct and of residue degree \(1\).

Because \(p\equiv 1\pmod 4\), the polynomial \(X^2+1\) splits over \(\mathbb F_p\). Therefore every \(\mathfrak p_j\) splits in \(K/F\):

\[ \mathfrak p_j\mathcal O_K = \mathfrak P_j \overline{\mathfrak P}_j, \]

where the bar denotes conjugation by \(c\).

Choose one prime \(\mathfrak P_j\) over each \(\mathfrak p_j\).

Define a homomorphism

\[ \varphi:\mathbb Z^d\longrightarrow \operatorname{Cl}(K) \]

by

\[ \varphi(e_1,\dots,e_d) = \left[ \prod_{j=1}^d \mathfrak P_j^{e_j} \right]. \]

Consider the cube

\[ Q_L=\{0,1,\dots,L\}^d. \]

It has \((L+1)^d\) elements. Since the class group has size \(h(K)\), by the pigeonhole principle there is a subset \(S\subseteq Q_L\) with

\[ |S|\ge \frac{(L+1)^d}{h(K)} \]

such that \(\varphi(v)\) is the same class for all \(v\in S\).

Fix some \(v_0\in S\). For every \(v\in S\), put

\[ w=v-v_0. \]

Then \(w=(w_1,\dots,w_d)\in[-L,L]^d\), and

\[ \varphi(w)=1. \]

Therefore the fractional ideal

\[ \mathfrak I_w = \prod_{j=1}^d \mathfrak P_j^{w_j} \]

is principal. Choose \(\eta_w\in K^\times\) with

\[ (\eta_w)=\mathfrak I_w. \]

Now define

\[ z_w=\frac{\eta_w}{c(\eta_w)}. \]

Then

\[ z_w\,c(z_w)=1. \]

Write

\[ z_w=x_w+\iota y_w, \qquad x_w,y_w\in F. \]

Equivalently,

\[ x_w=\frac{z_w+c(z_w)}2, \qquad y_w=\frac{z_w-c(z_w)}{2\iota}. \]

Since \(z_w c(z_w)=1\), we get

\[ x_w^2+y_w^2=1. \]

Next we check the denominator. The divisor of \(z_w\) is

\[ (z_w) = \prod_{j=1}^d \mathfrak P_j^{w_j} \overline{\mathfrak P}_j^{-w_j}. \]

Since \(|w_j|\le L\), every valuation of \(z_w\) at a prime over \(p\) is at least \(-L\), and all other valuations are \(0\). Hence

\[ z_w\in p^{-L}\mathcal O_K. \]

Also \(c(z_w)\in p^{-L}\mathcal O_K\). Therefore

\[ x_w=\frac{z_w+c(z_w)}2 \in (2p^L)^{-1}\mathcal O_K\cap F = (2p^L)^{-1}\mathcal O_F. \]

Similarly, since \(\iota\) is a unit of \(\mathcal O_K\),

\[ y_w=\frac{z_w-c(z_w)}{2\iota} \in (2p^L)^{-1}\mathcal O_F. \]

Finally, distinct \(w\)'s give distinct \(z_w\)'s, because the divisor of \(z_w\) is

\[ \prod_{j=1}^d \mathfrak P_j^{w_j} \overline{\mathfrak P}_j^{-w_j}, \]

which determines \(w\). Therefore the pairs \((x_w,y_w)\) are distinct.

Thus

\[ V_i = \{(x_w,y_w):v\in S\} \]

has size at least \((L+1)^d/h(K)\), and every element satisfies the desired properties. \(\square\)

4. A translated Følner box in the Minkowski lattice

We need finite additive sets in \(F_i\) which are large but almost invariant under all elements whose conjugates are bounded by \(1\).

The following lemma is the geometric engine.

Lemma 4: translated boxes with controlled size

Let \(F\) be a totally real field of degree \(d\) with

\[ \operatorname{rd}(F)\le \Delta. \]

Let \(m\ge 1\) be an integer, and let \(R>1\). Then there exist finite sets

\[ B^\circ\subseteq B\subseteq m^{-1}\mathcal O_F \]

such that:

  1. the interior set is large:

    \[ |B^\circ| \ge \left(\frac{2m(R-1)}{\sqrt\Delta}\right)^d; \]

  2. the outer set is not too large:

    \[ |B| \le (2mR+1)^d; \]

  3. if \(v\in m^{-1}\mathcal O_F\) satisfies

    \[ |\tau(v)|\le 1 \]

    for every real embedding \(\tau:F\hookrightarrow\mathbb R\), then

    \[ B^\circ+v\subseteq B. \]

Proof

Let

\[ \Phi:F\hookrightarrow \mathbb R^d \]

be the full real Minkowski embedding,

\[ \Phi(a)=(\tau(a))_{\tau:F\hookrightarrow\mathbb R}. \]

Let

\[ \Lambda=\Phi(m^{-1}\mathcal O_F). \]

This is a lattice in \(\mathbb R^d\) with covolume

\[ \operatorname{covol}(\Lambda) = m^{-d}\sqrt{|\operatorname{Disc}(F)|} \le m^{-d}\Delta^{d/2}. \]

For \(s>0\), write

\[ Q_s=[-s,s]^d. \]

By averaging over a fundamental parallelepiped of \(\Lambda\),

\[ \frac1{\operatorname{covol}(\Lambda)} \int_{\mathbb R^d/\Lambda} |\Lambda\cap(t+Q_{R-1})|\,dt = \frac{\operatorname{vol}(Q_{R-1})}{\operatorname{covol}(\Lambda)}. \]

Therefore there exists \(t\in\mathbb R^d\) such that

\[ |\Lambda\cap(t+Q_{R-1})| \ge \frac{(2(R-1))^d}{\operatorname{covol}(\Lambda)} \ge \left(\frac{2m(R-1)}{\sqrt\Delta}\right)^d. \]

Choose such a \(t\), and define

\[ B^\circ = \{a\in m^{-1}\mathcal O_F:\Phi(a)\in t+Q_{R-1}\}, \]
\[ B = \{a\in m^{-1}\mathcal O_F:\Phi(a)\in t+Q_R\}. \]

Then \(B^\circ\subseteq B\), and the lower bound for \(|B^\circ|\) follows.

Next we prove the upper bound for \(|B|\). If \(a\neq a'\) are elements of \(m^{-1}\mathcal O_F\), then

\[ m(a-a')\in\mathcal O_F\setminus\{0\}. \]

Thus

\[ \prod_{\tau}|\tau(m(a-a'))| = |N_{F/\mathbb Q}(m(a-a'))| \ge 1. \]

Therefore

\[ \max_\tau |\tau(a-a')|\ge \frac1m. \]

So the points of \(\Lambda\) are separated in \(\ell^\infty\)-norm by at least \(1/m\). Hence the closed \(\ell^\infty\)-balls of radius \(1/(2m)\) centered at points of \(\Lambda\cap(t+Q_R)\) have disjoint interiors. Their union is contained in

\[ t+Q_{R+1/(2m)}. \]

The \(\ell^\infty\)-ball of radius \(1/(2m)\) has volume \(m^{-d}\), and

\[ \operatorname{vol}(Q_{R+1/(2m)}) = (2R+1/m)^d. \]

Thus

\[ |B|\,m^{-d} \le (2R+1/m)^d, \]

so

\[ |B|\le (2mR+1)^d. \]

Finally, suppose \(v\in m^{-1}\mathcal O_F\) satisfies \(|\tau(v)|\le 1\) for every \(\tau\). If \(a\in B^\circ\), then

\[ \Phi(a)\in t+Q_{R-1}, \qquad \Phi(v)\in Q_1. \]

Therefore

\[ \Phi(a+v)\in t+Q_R, \]

so \(a+v\in B\). This proves \(B^\circ+v\subseteq B\). \(\square\)

5. Choosing the constants

We now freeze all parameters.

From Lemma 2, we have a constant \(H\) such that

\[ h(K_i)\le H^{d_i}. \]

Choose an integer \(L\ge 1\) so large that

\[ C:=\frac{L+1}{H}>\Delta. \]

Let

\[ m=2p^L. \]

Next choose \(R>1\) sufficiently large so that, defining

\[ \alpha = \frac{2m(R-1)}{\sqrt\Delta}, \]
\[ \beta = 2mR+1, \]

we have

\[ \Gamma := \frac{C\alpha^2}{\beta^2} >1. \]

This is possible because

\[ \frac{\alpha}{\beta} = \frac{2m(R-1)/\sqrt\Delta}{2mR+1} \longrightarrow \frac1{\sqrt\Delta} \]

as \(R\to\infty\). Hence

\[ \Gamma \longrightarrow \frac{C}{\Delta} >1. \]

Enlarge \(R\), if necessary, so that also

\[ \alpha>1. \]

Finally define

\[ \delta = \min\left\{ \frac{\log \Gamma}{4\log \beta}, \frac12 \right\}. \]

Since \(\Gamma>1\) and \(\beta>1\), we have

\[ \delta>0. \]

All constants \(p,\Delta,H,L,m,R,\alpha,\beta,\Gamma,\delta\) are now fixed once and for all, independent of \(i\).

6. Constructing the point sets

Fix \(i\). Let \(F=F_i\), \(d=d_i\), and let

\[ \sigma:F\hookrightarrow\mathbb R \]

be one chosen real embedding.

Apply Lemma 4 to \(F\), with the already fixed \(m\) and \(R\). We get finite sets

\[ B_i^\circ\subseteq B_i\subseteq m^{-1}\mathcal O_{F_i} \]

such that

\[ |B_i^\circ|\ge \alpha^{d_i}, \]
\[ |B_i|\le \beta^{d_i}, \]

and such that every \(v\in m^{-1}\mathcal O_{F_i}\) with all conjugates bounded by \(1\) satisfies

\[ B_i^\circ+v\subseteq B_i. \]

Now define

\[ P_i = \{(\sigma(a),\sigma(b)):a,b\in B_i\} \subset \mathbb R^2. \]

Since \(\sigma\) is injective,

\[ |P_i|=|B_i|^2. \]

In particular,

\[ |P_i|\le \beta^{2d_i}. \]

Also,

\[ |P_i| \ge |B_i^\circ|^2 \ge \alpha^{2d_i}. \]

Because \(\alpha>1\) and \(d_i\to\infty\), we have

\[ |P_i|\to\infty. \]

7. Counting unit distances

By Lemma 3, there is a set

\[ V_i\subseteq (m^{-1}\mathcal O_{F_i})^2 \]

such that every \((x,y)\in V_i\) satisfies

\[ x^2+y^2=1, \]

and

\[ |V_i| \ge \frac{(L+1)^{d_i}}{h(K_i)} \ge \left(\frac{L+1}{H}\right)^{d_i} = C^{d_i}. \]

Now fix \((x,y)\in V_i\). For every real embedding \(\tau:F_i\hookrightarrow\mathbb R\), we have

\[ \tau(x)^2+\tau(y)^2=1. \]

Hence

\[ |\tau(x)|\le 1, \qquad |\tau(y)|\le 1. \]

Therefore the translation property from Lemma 4 gives

\[ B_i^\circ+x\subseteq B_i, \qquad B_i^\circ+y\subseteq B_i. \]

Thus for every \(a,b\in B_i^\circ\), both points

\[ (\sigma(a),\sigma(b)) \]

and

\[ (\sigma(a+x),\sigma(b+y)) \]

belong to \(P_i\).

Moreover, their Euclidean distance is exactly

\[ \sqrt{\sigma(x)^2+\sigma(y)^2} = \sqrt{\sigma(x^2+y^2)} = 1. \]

Therefore every triple

\[ ((x,y),a,b) \in V_i\times B_i^\circ\times B_i^\circ \]

gives an ordered unit-distance pair in \(P_i\).

These ordered pairs are distinct. Indeed, if two triples produce the same ordered pair, then equality of the first point gives

\[ \sigma(a)=\sigma(a'), \qquad \sigma(b)=\sigma(b'), \]

so \(a=a'\) and \(b=b'\). Equality of the second point then gives

\[ \sigma(x)=\sigma(x'), \qquad \sigma(y)=\sigma(y'), \]

and hence \(x=x'\), \(y=y'\), because \(\sigma\) is injective.

Therefore the number of ordered unit-distance pairs in \(P_i\) is at least

\[ |V_i|\,|B_i^\circ|^2 \ge C^{d_i}\alpha^{2d_i} = (C\alpha^2)^{d_i}. \]

Since \(u(P_i)\) is half the number of ordered unit-distance pairs,

\[ u(P_i) \ge \frac12(C\alpha^2)^{d_i}. \]

Using the definition

\[ \Gamma=\frac{C\alpha^2}{\beta^2}, \]

we get

\[ u(P_i) \ge \frac12\Gamma^{d_i}\beta^{2d_i}. \]

8. Converting the exponential gain into a power gain

Recall that

\[ |P_i|\le \beta^{2d_i}. \]

Also, by the choice of \(\delta\),

\[ 2\delta\log\beta \le \frac12\log\Gamma. \]

Therefore

\[ \beta^{2\delta d_i} \le \Gamma^{d_i/2}. \]

Since \(d_i\to\infty\), after discarding finitely many indices we may assume

\[ \frac12\Gamma^{d_i} \ge \Gamma^{d_i/2} \ge \beta^{2\delta d_i}. \]

For those \(i\), we have

\[ u(P_i) \ge \frac12\Gamma^{d_i}\beta^{2d_i} \ge \beta^{2\delta d_i}\beta^{2d_i} = \beta^{2(1+\delta)d_i}. \]

Since \(|P_i|\le \beta^{2d_i}\), it follows that

\[ u(P_i) \ge |P_i|^{1+\delta}. \]

Discarding finitely many initial sets and reindexing the remaining infinite sequence, we obtain an infinite sequence \(\{P_i\}\) such that

\[ |P_i|\to\infty \]

and

\[ u(P_i)\ge |P_i|^{1+\delta} \]

for every \(i\).

This proves the theorem. \(\square\)

Summary of the mechanism

The construction can be summarized as follows.

  1. Pick high-degree totally real fields \(F_i\) with bounded root discriminant and with a fixed prime \(p\equiv1\pmod4\) split completely.

  2. Since \(p\) splits into \(d_i\) primes, the extension \(F_i(\iota)/F_i\) gives \(d_i\) independent split prime pairs. Class-group pigeonholing produces at least \(C^{d_i}\) elements

    \[ z=x+\iota y \]

    with

    \[ z\overline z=x^2+y^2=1. \]

    These give \(C^{d_i}\) genuine Euclidean unit directions under every real embedding.

  3. Build a finite additive set \(B_i\subset m^{-1}\mathcal O_{F_i}\) that is large but remains stable under adding any element whose conjugates are all bounded by \(1\). The translated-box argument gives

    \[ |B_i^\circ|\ge \alpha^{d_i}, \qquad |B_i|\le \beta^{d_i}. \]

  4. Embed one copy of \(F_i\) into \(\mathbb R\), and take

    \[ P_i=\sigma(B_i)\times\sigma(B_i)\subset\mathbb R^2. \]

    Every algebraic unit vector translates the interior \(B_i^\circ\times B_i^\circ\) to another part of \(P_i\), producing unit distances.

  5. The count is

    \[ u(P_i) \gtrsim C^{d_i}\alpha^{2d_i}, \qquad |P_i| \le \beta^{2d_i}. \]

    Choosing parameters so that

    \[ C\alpha^2>\beta^2 \]

    yields a fixed power saving:

    \[ u(P_i)\ge |P_i|^{1+\delta} \]

    for some absolute \(\delta>0\).

Assistant

Critical audit of the previous proof

The overall strategy is sound, but several points must be made precise.

  1. Arithmetic tower input. We need infinitely many totally real fields of bounded root discriminant in which a fixed prime \(q\equiv1\pmod4\) splits completely. This is not elementary; it comes from the \(T\)-split class-field-tower theorem of Golod–Shafarevich/Hajir–Maire. I state this input explicitly.

  2. Nonprincipal primes over \(q\). The primes above \(q\) need not be principal. The proof must use a class-group pigeonhole argument to produce many principal fractional ideals from bounded exponent vectors.

  3. Skew Minkowski lattices. A centered box in \(\mathcal O_F\) might not contain the expected number of points. The fix is to use translated boxes and average over the Minkowski torus.

  4. Denominators and the factor \(2\). If \(z=x+\iota y\), then

    \[ x=\frac{z+\bar z}{2},\qquad y=\frac{z-\bar z}{2\iota}, \]

    so a factor \(2\) must be included in the common denominator.

With these issues handled, the proof becomes rigorous.

Proof

Let \(q=5\). Thus \(q\equiv1\pmod4\).

We use the following standard arithmetic input.

1. Arithmetic input

Lemma 1: bounded-root-discriminant totally real split tower

There exist a constant \(\Delta<\infty\) and an infinite sequence of totally real number fields \(F_i\) such that, writing

\[ d_i=[F_i:\mathbb Q], \]

we have:

  1. \(d_i\to\infty\);
  2. \(q=5\) splits completely in \(F_i\);

  3. \(\operatorname{rd}(F_i)\le \Delta\), where

    \[ \operatorname{rd}(F_i)=|\operatorname{Disc}(F_i)|^{1/d_i}. \]

Justification

This is the \(T\)-split class-field-tower theorem of Golod–Shafarevich in the Hajir–Maire form: for any number field \(k\) and finite set \(T\) of places, there is a finite extension \(k'/k\) in which all places in \(T\) split completely and whose maximal everywhere-finite-unramified extension, with all primes above \(T\) split completely, is infinite.

Apply this to \(k=\mathbb Q\) and

\[ T=\{5,\infty\}. \]

We obtain a totally real field \(F_0\) in which \(5\) splits completely and an infinite extension \(\Omega/F_0\), unramified at all finite primes, in which all primes above \(5\) and all real places split completely.

Take finite subextensions \(F_i/F_0\) with \([F_i:\mathbb Q]\to\infty\). Since \(F_i/F_0\) is unramified at finite primes,

\[ \operatorname{rd}(F_i)=\operatorname{rd}(F_0). \]

Also, all \(F_i\) remain totally real, and \(5\) splits completely in each \(F_i\). Set

\[ \Delta=\operatorname{rd}(F_0). \]

2. Class-number control

For each \(i\), define

\[ K_i=F_i(\iota), \qquad \iota^2=-1. \]

Since \(F_i\) is totally real, \(\iota\notin F_i\), so

\[ [K_i:\mathbb Q]=2d_i. \]

We need a uniform exponential upper bound for \(h(K_i)\).

Lemma 2: exponential class-number bound

There exists a constant \(H<\infty\), independent of \(i\), such that

\[ h(K_i)\le H^{d_i}. \]

Proof

Let \(F=F_i\), \(K=K_i\), and \(d=d_i\).

The relative discriminant of \(K/F\) divides \(4\mathcal O_F\), because \(K=F(\iota)\) is generated by a root of \(X^2+1\), whose discriminant is \(-4\). Therefore

\[ |\operatorname{Disc}(K)| \le |\operatorname{Disc}(F)|^2 4^d. \]

Hence

\[ \operatorname{rd}(K) = |\operatorname{Disc}(K)|^{1/(2d)} \le 2\operatorname{rd}(F) \le 2\Delta. \]

Now let \(L\) be any number field of degree \(n\) and root discriminant at most \(\rho\). Minkowski’s theorem implies that every ideal class of \(L\) contains an integral ideal of norm at most

\[ M_L \le \left(\frac4\pi\right)^{r_2} \frac{n!}{n^n} |\operatorname{Disc}(L)|^{1/2} \le \left(\left(\frac4\pi\right)^{1/2}\rho^{1/2}\right)^n. \]

The number of ideals of norm at most \(M_L\) is at most

\[ M_L^2\zeta_L(2). \]

Also,

\[ \zeta_L(2)\le \zeta(2)^n, \]

because each Euler factor of \(\zeta_L(2)\) is bounded by the corresponding \(n\)-th power Euler factor of \(\zeta(2)\).

Thus

\[ h(L)\le C(\rho)^n \]

for some constant \(C(\rho)\).

Applying this to \(K_i\), whose degree is \(2d_i\) and whose root discriminant is at most \(2\Delta\), gives

\[ h(K_i)\le H^{d_i} \]

for some constant \(H\) depending only on \(\Delta\). \(\square\)

3. Many algebraic unit vectors

We now produce many solutions of

\[ x^2+y^2=1 \]

inside \(F_i\), with uniformly bounded denominators.

Lemma 3: controlled norm-one vectors

Fix an integer \(L\ge1\). For every \(i\), there exists a set

\[ V_i\subseteq \bigl((2q^L)^{-1}\mathcal O_{F_i}\bigr)^2 \]

such that:

  1. every \((x,y)\in V_i\) satisfies

    \[ x^2+y^2=1; \]
  2. the elements of \(V_i\) are distinct;
  3. \[ |V_i|\ge \frac{(L+1)^{d_i}}{h(K_i)}. \]

Proof

Fix \(i\), and write \(F=F_i\), \(K=K_i\), \(d=d_i\).

Since \(q\) splits completely in \(F\),

\[ q\mathcal O_F=\mathfrak p_1\cdots \mathfrak p_d, \]

with each residue field \(\mathcal O_F/\mathfrak p_j\cong\mathbb F_q\).

Because \(q\equiv1\pmod4\), the polynomial \(X^2+1\) splits over \(\mathbb F_q\). Hence each \(\mathfrak p_j\) splits in \(K/F\):

\[ \mathfrak p_j\mathcal O_K = \mathfrak P_j\overline{\mathfrak P}_j. \]

Choose one prime \(\mathfrak P_j\) above each \(\mathfrak p_j\).

Define

\[ \varphi:\mathbb Z^d\to \operatorname{Cl}(K) \]

by

\[ \varphi(e_1,\dots,e_d) = \left[ \prod_{j=1}^d \mathfrak P_j^{e_j} \right]. \]

Consider the cube

\[ Q_L=\{0,1,\dots,L\}^d. \]

By pigeonholing among the \(h(K)\) ideal classes, there is a subset \(S\subseteq Q_L\) with

\[ |S|\ge \frac{(L+1)^d}{h(K)} \]

such that \(\varphi(v)\) is constant on \(S\).

Fix \(v_0\in S\). For every \(v\in S\), put

\[ w=v-v_0. \]

Then \(w\in[-L,L]^d\), and

\[ \varphi(w)=1. \]

Therefore the fractional ideal

\[ \mathfrak I_w=\prod_{j=1}^d \mathfrak P_j^{w_j} \]

is principal. Choose \(\eta_w\in K^\times\) such that

\[ (\eta_w)=\mathfrak I_w. \]

Set

\[ z_w=\frac{\eta_w}{\overline{\eta_w}}. \]

Then

\[ z_w\overline{z_w}=1. \]

Write uniquely

\[ z_w=x_w+\iota y_w, \qquad x_w,y_w\in F. \]

Then

\[ x_w^2+y_w^2=1. \]

The divisor of \(z_w\) is

\[ (z_w) = \prod_{j=1}^d \mathfrak P_j^{w_j} \overline{\mathfrak P}_j^{-w_j}. \]

Since \(|w_j|\le L\), all valuations of \(z_w\) at primes over \(q\) are at least \(-L\), and all other valuations are nonnegative. Hence

\[ z_w\in q^{-L}\mathcal O_K. \]

Also \(\overline{z_w}\in q^{-L}\mathcal O_K\). Therefore

\[ x_w=\frac{z_w+\overline{z_w}}2 \in (2q^L)^{-1}\mathcal O_K\cap F = (2q^L)^{-1}\mathcal O_F. \]

Similarly,

\[ y_w=\frac{z_w-\overline{z_w}}{2\iota} \in (2q^L)^{-1}\mathcal O_F. \]

Distinct \(w\)’s give distinct divisors of \(z_w\), hence distinct \(z_w\), hence distinct pairs \((x_w,y_w)\). Therefore the set

\[ V_i=\{(x_w,y_w):v\in S\} \]

has the desired size and properties. \(\square\)

4. Translated boxes in the Minkowski embedding

Let \(F\) be totally real of degree \(d\). Let

\[ \Phi:F\hookrightarrow \mathbb R^d \]

be the full Minkowski embedding,

\[ \Phi(a)=(\tau(a))_{\tau:F\hookrightarrow\mathbb R}. \]

Lemma 4: large translated boxes with controlled boundary

Let \(F\) be totally real of degree \(d\) with \(\operatorname{rd}(F)\le \Delta\). Let \(M\ge1\) be an integer and let \(R>1\). Then there exist finite sets

\[ B^\circ\subseteq B\subseteq M^{-1}\mathcal O_F \]

such that:

  1. \[ |B^\circ| \ge \left(\frac{2M(R-1)}{\sqrt\Delta}\right)^d; \]
  2. \[ |B| \le (2MR+1)^d; \]

  3. if \(v\in M^{-1}\mathcal O_F\) satisfies

    \[ |\tau(v)|\le1 \]

    for every real embedding \(\tau:F\hookrightarrow\mathbb R\), then

    \[ B^\circ+v\subseteq B. \]

Proof

Let

\[ \Lambda=\Phi(M^{-1}\mathcal O_F)\subset \mathbb R^d. \]

Its covolume is

\[ \operatorname{covol}(\Lambda) = M^{-d}\sqrt{|\operatorname{Disc}(F)|} \le M^{-d}\Delta^{d/2}. \]

For \(s>0\), let

\[ Q_s=[-s,s]^d. \]

By averaging over \(\mathbb R^d/\Lambda\), there exists \(t\in\mathbb R^d\) such that

\[ |\Lambda\cap(t+Q_{R-1})| \ge \frac{\operatorname{vol}(Q_{R-1})}{\operatorname{covol}(\Lambda)} \ge \left(\frac{2M(R-1)}{\sqrt\Delta}\right)^d. \]

Define

\[ B^\circ = \{a\in M^{-1}\mathcal O_F:\Phi(a)\in t+Q_{R-1}\}, \]
\[ B = \{a\in M^{-1}\mathcal O_F:\Phi(a)\in t+Q_R\}. \]

Then \(B^\circ\subseteq B\), and the lower bound for \(|B^\circ|\) holds.

For the upper bound on \(|B|\), note that if \(a\neq a'\) in \(M^{-1}\mathcal O_F\), then

\[ M(a-a')\in\mathcal O_F\setminus\{0\}. \]

Thus

\[ \prod_\tau |\tau(M(a-a'))| = |N_{F/\mathbb Q}(M(a-a'))| \ge1. \]

Hence

\[ \max_\tau |\tau(a-a')|\ge \frac1M. \]

So distinct points of \(\Lambda\) are separated by at least \(1/M\) in \(\ell^\infty\)-norm. Therefore the open \(\ell^\infty\)-cubes of radius \(1/(2M)\) centered at the points of \(\Lambda\cap(t+Q_R)\) are disjoint and lie inside \(t+Q_{R+1/(2M)}\). Hence

\[ |B|M^{-d} \le (2R+1/M)^d, \]

so

\[ |B|\le (2MR+1)^d. \]

Finally, if \(v\in M^{-1}\mathcal O_F\) and \(|\tau(v)|\le1\) for every \(\tau\), then

\[ \Phi(v)\in Q_1. \]

Thus

\[ \Phi(B^\circ)+\Phi(v) \subseteq (t+Q_{R-1})+Q_1 \subseteq t+Q_R. \]

So \(B^\circ+v\subseteq B\). \(\square\)

5. Choosing constants

From Lemma 2, choose \(H\) such that

\[ h(K_i)\le H^{d_i} \]

for every \(i\).

Choose an integer \(L\ge1\) so large that

\[ C:=\frac{L+1}{H}>\Delta. \]

Let

\[ M=2q^L. \]

For \(R>1\), define

\[ \alpha= \frac{2M(R-1)}{\sqrt\Delta}, \qquad \beta=2MR+1. \]

Then

\[ \frac{\alpha}{\beta} = \frac{2M(R-1)/\sqrt\Delta}{2MR+1} \longrightarrow \frac1{\sqrt\Delta} \]

as \(R\to\infty\). Hence

\[ \frac{C\alpha^2}{\beta^2}\longrightarrow \frac{C}{\Delta}>1. \]

Choose \(R\) large enough that

\[ \Gamma:=\frac{C\alpha^2}{\beta^2}>1 \]

and also \(\alpha>1\).

Finally choose

\[ \delta = \min\left\{ \frac{\log \Gamma}{4\log \beta}, \frac12 \right\}. \]

Then \(\delta>0\), and all constants are absolute.

6. Construction of the point sets

Fix \(i\), and write \(F=F_i\), \(d=d_i\).

Apply Lemma 4 to \(F\), with the fixed \(M\) and \(R\). We obtain

\[ B_i^\circ\subseteq B_i\subseteq M^{-1}\mathcal O_F \]

such that

\[ |B_i^\circ|\ge \alpha^d, \qquad |B_i|\le \beta^d, \]

and such that \(B_i^\circ\) is stable under all translations \(v\in M^{-1}\mathcal O_F\) with all conjugates bounded by \(1\).

Choose one real embedding

\[ \sigma:F\hookrightarrow\mathbb R. \]

Define

\[ P_i = \{(\sigma(a),\sigma(b)):a,b\in B_i\} \subset\mathbb R^2. \]

Since \(\sigma\) is injective,

\[ |P_i|=|B_i|^2\le \beta^{2d}. \]

Also,

\[ |P_i|\ge |B_i^\circ|^2\ge \alpha^{2d}. \]

Because \(\alpha>1\) and \(d_i\to\infty\), we have

\[ |P_i|\to\infty. \]

7. Counting unit distances

By Lemma 3 and the class-number bound,

\[ |V_i| \ge \frac{(L+1)^d}{h(K_i)} \ge \left(\frac{L+1}{H}\right)^d = C^d. \]

Take any \((x,y)\in V_i\). Then

\[ x^2+y^2=1. \]

For every real embedding \(\tau:F\hookrightarrow\mathbb R\),

\[ \tau(x)^2+\tau(y)^2=1. \]

Therefore

\[ |\tau(x)|\le1, \qquad |\tau(y)|\le1. \]

Since \(x,y\in M^{-1}\mathcal O_F\), Lemma 4 gives

\[ B_i^\circ+x\subseteq B_i, \qquad B_i^\circ+y\subseteq B_i. \]

Thus for every \(a,b\in B_i^\circ\), both points

\[ (\sigma(a),\sigma(b)) \]

and

\[ (\sigma(a+x),\sigma(b+y)) \]

lie in \(P_i\). Their Euclidean distance is exactly

\[ \sqrt{\sigma(x)^2+\sigma(y)^2} = \sqrt{\sigma(x^2+y^2)} = 1. \]

Moreover, the map

\[ ((x,y),a,b) \mapsto \left( (\sigma(a),\sigma(b)), (\sigma(a+x),\sigma(b+y)) \right) \]

is injective. Indeed, equality of the first point forces \(a=a'\) and \(b=b'\), and equality of the second point then forces \(x=x'\) and \(y=y'\).

Hence the number of ordered unit-distance pairs in \(P_i\) is at least

\[ |V_i|\,|B_i^\circ|^2 \ge C^d\alpha^{2d} = (C\alpha^2)^d. \]

Since \(u(P_i)\) is half the number of ordered unit-distance pairs,

\[ u(P_i) \ge \frac12(C\alpha^2)^d. \]

Using

\[ \Gamma=\frac{C\alpha^2}{\beta^2}, \]

we get

\[ u(P_i) \ge \frac12\Gamma^d\beta^{2d}. \]

8. Converting the exponential gain to a power gain

Because

\[ \delta\le \frac{\log\Gamma}{4\log\beta}, \]

we have

\[ \beta^{2\delta d}\le \Gamma^{d/2}. \]

Since \(\Gamma>1\), for all sufficiently large \(d\),

\[ \frac12\Gamma^d\ge \Gamma^{d/2}\ge \beta^{2\delta d}. \]

Therefore, for all sufficiently large \(i\),

\[ u(P_i) \ge \beta^{2d}\beta^{2\delta d} = \beta^{2(1+\delta)d}. \]

But

\[ |P_i|\le \beta^{2d}, \]

so

\[ |P_i|^{1+\delta} \le \beta^{2(1+\delta)d}. \]

Hence, for all sufficiently large \(i\),

\[ u(P_i)\ge |P_i|^{1+\delta}. \]

Discard finitely many initial indices and reindex the remaining infinite sequence. Then

\[ |P_i|\to\infty \]

and

\[ u(P_i)\ge |P_i|^{1+\delta} \]

for every \(i\).

This proves the theorem. \(\square\)
