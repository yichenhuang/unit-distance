Assistant

Below is how I would organize the search for a proof. I will use the following common reduction throughout.

A very useful sufficient condition is:

Find finite \(P\subset \mathbb R^2\) and a large set \(V\subset S^1\) of unit vectors such that, for every \(v\in V\),

\[ |P\cap (P-v)|\ge c|P| \]

with \(c\) not too small. Then

\[ u(P)\ \ge\ \frac12\sum_{v\in V}|P\cap(P-v)| \ \ge\ \frac c2 |V||P|. \]

Thus if \(|V|\ge |P|^\delta\), we are done.

So the problem is to build a finite planar set that is simultaneously almost invariant under polynomially many distinct unit translations. The classical integer-lattice construction does this with \(|V|=|P|^{o(1)}\); to get a fixed power, we need a source of many more unit translations with controlled additive complexity.

I would pursue the following three approaches.

Approach 1 — S-arithmetic / CM-field construction: many norm-one \(S\)-units and adelic Følner boxes

Core idea

The usual lattice construction lives in the Gaussian rationals \(\mathbb Q(i)\). Unit directions are obtained from Gaussian integers:

\[ \alpha=\frac{z}{\overline z},\qquad |\alpha|=1. \]

If \(z\) has many prime factors \(p_j\equiv 1\pmod 4\), then one gets many directions by choosing different exponent patterns. The bottleneck is that the rational primes \(p_j\) grow, so the common denominator grows too fast, giving only \(n^{o(1)}\) directions.

The key idea is to replace \(\mathbb Q(i)\) by a sequence of high-degree CM fields in which a fixed small rational prime \(p\) splits into many prime ideals. Then one can get exponentially many norm-one \(S\)-units using only denominators above one fixed small prime. This should give a fixed power gain.

This is, in my view, the most promising route.

Step 1: Choose a CM tower with many small split primes

Let \(F_j\) be a sequence of totally real fields with \([F_j:\mathbb Q]=d_j\to\infty\), bounded root discriminant, and such that a fixed rational prime \(p\) splits completely in every \(F_j\). One way to aim for this is to start with a totally real field with an infinite narrow Hilbert class field tower and with a principal degree-one prime above \(p\); then that prime splits completely throughout the tower.

Now put

\[ K_j=F_j(i), \]

choosing \(p\equiv 1\pmod 4\), for instance \(p=5\), so that every prime of \(F_j\) above \(p\) splits further in \(K_j\). Thus

\[ p\mathcal O_{F_j}=\mathfrak q_{1}\cdots \mathfrak q_{d_j}, \]

and in \(K_j\),

\[ \mathfrak q_\ell\mathcal O_{K_j}=\mathfrak p_\ell\overline{\mathfrak p}_\ell. \]

The conjugation bar is the CM conjugation.

Step 2: Produce exponentially many norm-one \(S\)-units

Let \(S_j\) be the set of primes of \(K_j\) above \(p\). For an exponent vector

\[ e=(e_1,\dots,e_{d_j})\in [-E,E]^{d_j}\cap \mathbb Z^{d_j}, \]

consider the anti-invariant fractional ideal

\[ \mathfrak a_e = \prod_{\ell=1}^{d_j} \left(\frac{\mathfrak p_\ell}{\overline{\mathfrak p}_\ell}\right)^{e_\ell}. \]

If \(\mathfrak a_e\) is principal, say \(\mathfrak a_e=(\beta_e)\), then

\[ \alpha_e:=\frac{\beta_e}{\overline{\beta_e}} \]

satisfies

\[ \alpha_e\overline{\alpha_e}=1. \]

Therefore, under every complex embedding \(\tau:K_j\hookrightarrow \mathbb C\),

\[ |\tau(\alpha_e)|=1. \]

Even if not every \(\mathfrak a_e\) is principal, one can use a class-group pigeonhole argument. Since the root discriminants are bounded, class numbers grow at most exponentially:

\[ h(K_j)\le C^{d_j} \]

for some absolute \(C\). Choosing \(E\) fixed but large enough so that

\[ 2E+1>C, \]

the number of exponent vectors modulo the class group is still exponential in \(d_j\). Taking quotients of vectors in the same class yields exponentially many principal anti-invariant ideals, hence exponentially many distinct norm-one \(S\)-units.

So one expects a set

\[ \mathcal U_j\subset K_j^\times \]

with

  1. \(\alpha\overline{\alpha}=1\) for every \(\alpha\in\mathcal U_j\);
  2. \(\alpha\) is an \(S_j\)-unit with valuations bounded by a fixed constant depending only on \(E\);
  3. \[ |\mathcal U_j|\ge \rho^{d_j} \]

    for some fixed \(\rho>1\).

Because \(K_j=F_j(i)\), we can write

\[ \alpha=x_\alpha+i y_\alpha \]

with \(x_\alpha,y_\alpha\in F_j\). The identity \(\alpha\overline{\alpha}=1\) becomes

\[ x_\alpha^2+y_\alpha^2=1 \]

inside \(F_j\). Under the distinguished real embedding \(\sigma:F_j\hookrightarrow \mathbb R\), this gives the Euclidean unit vector

\[ v_\alpha=(\sigma(x_\alpha),\sigma(y_\alpha))\in S^1. \]

Thus \(\mathcal U_j\) gives exponentially many unit directions in the real plane.

Step 3: Build large finite one-dimensional sets stable under all \(x_\alpha,y_\alpha\)

We need finite \(A_j\subset F_j\) such that for every \(\alpha\in \mathcal U_j\),

\[ |A_j\cap(A_j-x_\alpha)|,\ |A_j\cap(A_j-y_\alpha)| \]

are both large.

A natural choice is an adelic box of \(S\)-integers. Fix constants \(L,R\), with \(L\) larger than the denominator bound of all \(x_\alpha,y_\alpha\). Define

\[ A_j = \left\{ a\in F_j: \begin{array}{l} v_{\mathfrak q}(a)\ge -L \text{ for every } \mathfrak q\mid p,\\ v_{\mathfrak r}(a)\ge 0 \text{ for every finite } \mathfrak r\nmid p,\\ |\tau(a)|\le R \text{ for every real embedding } \tau:F_j\hookrightarrow \mathbb R \end{array} \right\}. \]

This is finite. By geometry-of-numbers estimates for adelic boxes, because the root discriminants of \(F_j\) are bounded and \(p\) splits completely,

\[ |A_j|\asymp B^{d_j} \]

for some fixed \(B>1\), depending on \(p,L,R\), but not on \(j\).

Now, because \(x_\alpha,y_\alpha\) have bounded denominators at primes above \(p\) and are integral elsewhere, the \(p\)-adic conditions are stable under translation by \(x_\alpha,y_\alpha\). Also, because

\[ \tau(x_\alpha)^2+\tau(y_\alpha)^2=1 \]

for every real embedding \(\tau\), we have

\[ |\tau(x_\alpha)|,\ |\tau(y_\alpha)|\le 1. \]

Therefore, if \(a\in A_j\) lies away from the archimedean boundary, then \(a+x_\alpha\in A_j\), and similarly for \(y_\alpha\).

Quantitatively, for \(R\) sufficiently large one should get

\[ |A_j\cap(A_j-x_\alpha)|\ge \lambda^{d_j}|A_j|, \]

and similarly for \(y_\alpha\), with \(\lambda\in(0,1)\) as close to \(1\) as desired by increasing \(R\).

Step 4: Form the planar point set and count unit distances

Let

\[ P_j=\sigma(A_j)\times \sigma(A_j)\subset \mathbb R^2. \]

Then

\[ |P_j|=|A_j|^2\asymp B^{2d_j}. \]

For each \(\alpha\in\mathcal U_j\), the vector

\[ v_\alpha=(\sigma(x_\alpha),\sigma(y_\alpha)) \]

has length \(1\). Moreover,

\[ |P_j\cap(P_j-v_\alpha)| = |A_j\cap(A_j-x_\alpha)|\cdot |A_j\cap(A_j-y_\alpha)| \ge \lambda^{2d_j}|A_j|^2. \]

Summing over \(\alpha\in\mathcal U_j\), and losing only a harmless factor to account for opposite directions, gives

\[ u(P_j) \ge c\,|\mathcal U_j|\,\lambda^{2d_j}|A_j|^2 \ge c\,(\rho\lambda^2)^{d_j}|P_j|. \]

Choose \(R\) large enough so that \(\rho\lambda^2>1\). Since

\[ |P_j|\asymp B^{2d_j}, \]

we get

\[ (\rho\lambda^2)^{d_j} = |P_j|^\delta \]

for

\[ \delta = \frac{\log(\rho\lambda^2)}{2\log B}>0. \]

Thus

\[ u(P_j)\ge c|P_j|^{1+\delta}. \]

This is already essentially a proof blueprint.

Main technical tasks

The hard parts to make rigorous are:

  1. Field tower selection. Need a sequence of totally real fields \(F_j\) with bounded root discriminant and a fixed prime \(p\) splitting completely. Class field tower constructions should be the natural tool.

  2. Counting norm-one \(S\)-units. One must prove that the anti-invariant \(S\)-unit group supplies at least \(\rho^{d_j}\) distinct elements with uniformly bounded \(p\)-adic denominator exponents. The class-group pigeonhole argument should handle the non-principal ideal issue.

  3. Uniform adelic box estimates. Need lower and upper bounds

    \[ |A_j|\asymp B^{d_j} \]

    and uniform overlap estimates under translations by \(x_\alpha,y_\alpha\).

  4. Collision control. Distinct \(\alpha\)'s should yield distinct Euclidean unit directions except for the obvious \(\alpha\leftrightarrow \alpha^{-1}\) symmetry. This is manageable because the distinguished embedding is injective on \(K_j\).

Why this is my top-ranked approach

This approach directly generalizes the classical Gaussian-integer construction, but it avoids the classical bottleneck by replacing many growing rational primes with many prime ideals of one fixed small norm. It also naturally gives the exact unit equation \(x^2+y^2=1\), not merely an approximate one.

The expected exponent \(\delta\) may be tiny, but it is absolute and positive, which is all the theorem requires.

Approach 2 — Finite-field unit graphs and S-arithmetic lifting

Core idea

Over a finite field \(\mathbb F_q\), the unit-distance graph in \(\mathbb F_q^2\) is extremely dense. Let

\[ U_q=\{(a,b)\in\mathbb F_q^2:a^2+b^2=1\}. \]

For odd \(q\), \(|U_q|=q+O(1)\). The Cayley graph on \(\mathbb F_q^2\) with generating set \(U_q\) has

\[ N=q^2 \]

vertices and roughly

\[ \frac12 q^2|U_q|\sim \frac12 q^3 = \frac12 N^{3/2} \]

edges.

This is far denser than what is possible in the real plane, where crossing-lemma arguments give \(O(n^{4/3})\). So one cannot hope to lift the full finite-field graph. But the finite-field graph can serve as a combinatorial template. One can thin it to a crossing-compatible density and then try to lift the surviving structure to \(\mathbb R^2\).

A possible thinning regime

Take a random subset of vertices of density \(q^{-a}\). Then the expected number of vertices is

\[ n\sim q^{2-a}, \]

and the expected number of inherited unit edges is

\[ m\sim q^{3-2a}. \]

The resulting exponent is

\[ \frac{\log m}{\log n} = \frac{3-2a}{2-a}. \]

For example, taking \(a=3/4\) gives

\[ n\sim q^{5/4},\qquad m\sim q^{3/2}, \]

so

\[ m\sim n^{6/5}. \]

This would already give \(\delta=1/5\), safely below the \(4/3\) crossing-lemma barrier.

Thus one can aim to lift not the full finite-field graph, but a structured subgraph with degree \(q^{\theta}\) for some \(\theta>0\).

Lifting philosophy

The finite-field construction is additive: vertices are elements of \(\mathbb F_q^2\), and edges are translations by elements of \(U_q\). To lift it to the real plane, we need a characteristic-zero model where many finite-field unit directions become genuine Euclidean unit vectors.

A good way to do this is through norm-one tori.

For example, identify \(\mathbb F_q^2\) with \(\mathbb F_{q^2}\). The finite-field unit circle is essentially the norm-one group

\[ T_q=\{z\in\mathbb F_{q^2}^\times:N_{\mathbb F_{q^2}/\mathbb F_q}(z)=1\}, \]

which has \(q+1\) elements.

One then tries to lift \(T_q\) to a characteristic-zero norm-one torus in a CM field. This is very close in spirit to Approach 1. The elements of the finite-field norm-one torus should lift to norm-one \(S\)-units

\[ \alpha\overline \alpha=1 \]

in a CM field, which then give genuine Euclidean unit vectors after taking real and imaginary parts.

The vertices can be lifted to an adelic box or \(p\)-adic digit box, chosen so that translations by many lifted unit directions preserve a large fraction of the box.

More algebraic formulation

A finite-field unit graph can be written as a system of equations

\[ p_v-p_w\in U_q. \]

A lift would require assigning characteristic-zero points \(P_v\in \mathbb R^2\) and unit vectors \(u_e\in S^1\) such that

\[ P_w-P_v=u_e \]

for each edge \(e=(v,w)\), and all cycle sums vanish:

\[ \sum_{e\in C}\pm u_e=0. \]

The finite-field graph gives these equations modulo \(p\). One wants a structured situation where these modular cycle identities lift to exact real identities. There are several possible mechanisms:

  1. Teichmüller / \(S\)-unit lifting. Lift finite-field norm-one elements to \(p\)-adic or \(S\)-unit norm-one elements in a CM field, then use a distinguished complex embedding.

  2. Tropical / Puiseux lifting. Construct the configuration first over a real closed non-Archimedean field, using valuation data to mimic finite-field arithmetic. Then apply Tarski transfer to obtain a real configuration.

  3. Rigid algebraic lifting. Choose a carefully structured subgraph whose cycle equations are not independent but come from a low-rank algebraic group. Then use an implicit-function or Hensel-type argument to lift the solution.

Expected edge count

Suppose one obtains a lifted real configuration with

\[ n\asymp q^\beta \]

vertices and average degree

\[ d_{\mathrm{avg}}\asymp q^\gamma \]

for some \(\gamma>0\). Then

\[ u(P)\asymp n q^\gamma = n^{1+\gamma/\beta}. \]

Thus any positive ratio \(\gamma/\beta\) gives the desired theorem.

The finite-field graphs naturally have \(\gamma\) comparable to \(1\), so even after substantial thinning or loss during lifting, there should be room to keep a positive exponent.

Main technical tasks

  1. Avoid the real-solvability trap. A polynomial system having finite-field solutions does not automatically have real solutions. The lifting must preserve the positive-definite Euclidean equation

    \[ x^2+y^2=1 \]

    over an ordered field or through a CM embedding.

  2. Control representatives. If vertices are lifted from a finite quotient, one must ensure that differences of chosen representatives are exactly the desired unit vectors, not merely congruent to them modulo a lattice.

  3. Respect the crossing bound. The full finite-field unit graph is too dense for the real plane. One must thin it or use a graph family whose density is at most \(n^{4/3}\).

  4. Prevent collisions. Distinct lifted vertices must remain distinct in \(\mathbb R^2\).

Why this is promising but ranked second

Finite-field unit graphs provide the right combinatorial objects: they have many unit directions and the same “two unit circles meet in at most two points” flavor as the Euclidean plane. However, the passage from finite-field incidence to exact real Euclidean distance is delicate. The lifting issues are substantial.

Still, this approach is useful because it can guide the S-arithmetic construction in Approach 1. In fact, Approach 1 can be interpreted as a carefully controlled characteristic-zero lift of finite-field norm-one tori.

Approach 3 — Rotationally symmetric layered constructions using many compatible radii

Core idea

Build \(P\) as a union of regular \(M\)-gons on many concentric circles. Let

\[ \Omega_M=\{e^{2\pi i k/M}:0\le k<M\}. \]

For a set of radii \(R\subset \mathbb R_{>0}\), define

\[ P=P(M,R):=\bigcup_{r\in R} r\Omega_M. \]

If \(r,s\in R\), then a point on the circle of radius \(r\) and a point on the circle of radius \(s\) are at distance \(1\) exactly when the angle gap \(\theta\) satisfies

\[ r^2+s^2-2rs\cos\theta=1. \]

Thus the pair \((r,s)\) is compatible with the \(M\)-fold symmetry if

\[ \frac{r^2+s^2-1}{2rs} \in \left\{ \cos\frac{2\pi a}{M}:a\in\mathbb Z \right\}. \]

Whenever \((r,s)\) is compatible, the two corresponding \(M\)-gons contribute \(\gg M\) unit distances.

So the problem becomes:

Find \(M\) and a large radius set \(R\) such that the compatibility graph \(H\) on \(R\), where \(r\sim s\) if the above condition holds, has many edges.

If \(|R|=t\) and \(H\) has \(E(H)\) edges, then

\[ |P|\asymp Mt, \]

and

\[ u(P)\gg M E(H). \]

Thus if \(E(H)\gg t^{1+\varepsilon}\) and \(t\) is a fixed power of \(M\), we get a power saving over linear.

For example, if \(H\) is dense, \(E(H)\asymp t^2\), and \(t=M^\beta\), then

\[ |P|\asymp M^{1+\beta}, \]

while

\[ u(P)\gg M^{1+2\beta}. \]

Hence

\[ u(P)\gg |P|^{1+\delta} \]

with

\[ \delta=\frac{\beta}{1+\beta}. \]

So even a moderately dense compatibility graph would prove the theorem.

How one might find many compatible radii

The compatibility condition is a law-of-cosines equation:

\[ r^2+s^2-2rs c=1, \qquad c=\cos\frac{2\pi a}{M}. \]

This suggests several possible algebraic parametrizations.

1. Chebyshev/cyclotomic identities

If radii are expressed using Chebyshev values, such as

\[ r_m=\frac{\sin(m\theta)}{\sin\theta}, \]

then law-of-cosines identities become exact trigonometric identities. For example,

\[ r_m^2+r_{m+1}^2-2r_mr_{m+1}\cos\theta=1. \]

This gives many compatible adjacent pairs. The challenge is to make the compatibility graph genuinely superlinear, not merely a path-like graph.

One would look for richer Chebyshev identities where many pairs \((m,n)\) yield distance \(1\) for allowed angle labels.

2. Norm-one torus parametrization

Let \(\alpha\) be a norm-one element in a CM field, so that \(|\sigma(\alpha)|=1\). Its real part is a cosine:

\[ \frac{\alpha+\alpha^{-1}}2=\cos\theta. \]

The compatibility equation becomes algebraic in \(\alpha\). One can attempt to choose radii \(r_\xi\) indexed by \(S\)-units \(\xi\), with edge labels also coming from norm-one \(S\)-units. Then the law-of-cosines condition may reduce to multiplicative identities in an \(S\)-unit group.

This is again related to Approach 1, but the geometric output would be more visually explicit: many concentric regular polygons with many cross-layer unit distances.

3. Finite-field label graphs

One can choose a dense graph \(G\) on labels and assign to each edge \(ij\) a residue \(a_{ij}\in\mathbb Z/M\). The goal is to solve

\[ r_i^2+r_j^2-2r_ir_j\cos\frac{2\pi a_{ij}}M=1 \]

for many vertices \(i\).

If the labels \(a_{ij}\) come from an additive rule, such as

\[ a_{ij}=b_i-b_j, \]

then the system has extra structure and may become solvable through trigonometric parametrizations.

Why this is attractive

This approach has an extremely transparent edge count. Once one has a radius set \(R\) with a dense compatibility graph, the construction of \(P\) and the unit-distance count are immediate.

It also respects the crossing-lemma upper bound naturally: by tuning \(t\) relative to \(M\), one can aim for any exponent below \(4/3\).

Main technical obstacles

  1. Dense compatibility is overdetermined. Requiring a law-of-cosines identity for many pairs of radii imposes many equations on only \(t\) unknowns.

  2. Cyclotomic constructions alone likely give too few identities. If \(R\) is built only from ordinary regular-polygon chord lengths, exact unit identities reduce to vanishing sums of roots of unity, which tend to be too sparse. One needs a richer algebraic source, probably again involving \(S\)-units or high-degree fields.

  3. Need to control duplicate points. Different radii should not collapse, and the \(M\)-gons should not overlap in unexpected ways.

Why ranked third

This is a very clean geometric route, but the hard algebraic part is hidden inside the construction of a dense compatibility graph on the radii. It may ultimately be a good way to present a construction once the algebraic identities are known, but as a proof-discovery strategy it seems less direct than the S-arithmetic construction.

Ranking

1. CM \(S\)-unit + adelic box construction

This is the most promising. It directly targets the needed sufficient condition: many unit vectors under which a finite set is almost invariant. The number-field mechanism plausibly gives exponentially many directions in degree \(d\), while the point set has size only exponentially large in \(d\), yielding a fixed power.

The crucial conceptual gain is replacing the growing rational primes in the classical Gaussian construction by many prime ideals of one fixed small norm in high-degree fields.

2. Finite-field unit graphs plus real/S-arithmetic lifting

This is also promising, especially as a source of templates. Finite-field unit graphs already have the right combinatorial density. The main challenge is the lifting step: one must preserve the positive-definite real equation \(x^2+y^2=1\) exactly. The best lifting mechanism likely collapses back into the CM \(S\)-unit framework of Approach 1.

3. Rotationally symmetric layered construction

This has the cleanest geometric edge count and may be useful for exposition or optimization. However, finding a large radius set with a dense compatibility graph is a difficult algebraic constraint. I would keep this as a secondary route or as a possible geometric reformulation of the \(S\)-unit construction.

Next step I would take

I would try to turn Approach 1 into two precise lemmas:

  1. Norm-one \(S\)-unit lemma. There exist CM fields \(K_j=F_j(i)\) with \([F_j:\mathbb Q]\to\infty\) and sets \(\mathcal U_j\) of norm-one \(S\)-units such that

    \[ |\mathcal U_j|\ge \rho^{[F_j:\mathbb Q]} \]

    and all local denominators are uniformly bounded.

  2. Adelic Følner box lemma. For each \(F_j\), there exists \(A_j\subset F_j\) with

    \[ |A_j|\asymp B^{[F_j:\mathbb Q]} \]

    and such that every coordinate \(x_\alpha,y_\alpha\) coming from \(\alpha\in\mathcal U_j\) satisfies

    \[ |A_j\cap(A_j-x_\alpha)|,\ |A_j\cap(A_j-y_\alpha)| \ge \lambda^{[F_j:\mathbb Q]}|A_j|. \]

If these two lemmas are established with \(\rho\lambda^2>1\), then the theorem follows immediately by taking

\[ P_j=\sigma(A_j)\times\sigma(A_j)\subset \mathbb R^2. \]

That is the route I would prioritize.

Below is a complete development of the CM/\(S\)-unit strategy. I will keep all constants explicit enough to see where the positive exponent comes from. The proof is not optimized; the resulting \(\delta\) is extremely small, but it is absolute and positive.

The proof has four main ingredients:

  1. a totally real class-field tower in which a fixed prime \(p\equiv 1 \pmod 4\) splits completely;
  2. a bounded-root-discriminant class-number bound;
  3. a construction of exponentially many norm-one \(S\)-units in \(F(i)\);
  4. a finite “adelic/archimedean box” \(A\subset F\) that is almost invariant under all the corresponding coordinate translations.

Throughout, \(u(P)\) denotes the number of unordered unit-distance pairs, so \(2u(P)\) is the number of ordered unit-distance pairs.

1. A totally real tower with one fixed split prime

We first need the following standard consequence of the Golod–Shafarevich class-field-tower method.

Lemma 1 — Totally real tower with prescribed splitting

There exist a prime \(p\equiv 1 \pmod 4\), a constant \(\Delta>0\), and an infinite sequence of totally real number fields

\[ F_1,F_2,\dots \]

such that, writing \(d_i=[F_i:\mathbb Q]\),

  1. \(d_i\to\infty\);
  2. \(p\) splits completely in every \(F_i\);

  3. \(\operatorname{rd}(F_i)\le \Delta\) for every \(i\), where

    \[ \operatorname{rd}(F)=|D_F|^{1/[F:\mathbb Q]} \]

    is the root discriminant.

Proof

We take \(p=5\).

Choose \(t=20\) distinct rational primes

\[ q_1,\dots,q_t\equiv 1 \pmod {20}. \]

Let

\[ m=q_1q_2\cdots q_t, \qquad F_0=\mathbb Q(\sqrt m). \]

Since \(m\equiv 1\pmod 4\), the discriminant of \(F_0\) is \(m\). The field \(F_0\) is real quadratic. Also, because each \(q_j\equiv 1\pmod 5\), the integer \(m\) is a square modulo \(5\), so \(5\) splits in \(F_0\). Let \(T\) be the set of the two primes of \(F_0\) above \(5\).

Let \(F_0^{T,+}(2)\) denote the maximal pro-\(2\) extension of \(F_0\) that is unramified at all finite primes and in which every real place of \(F_0\), and also every prime in \(T\), splits completely. Let

\[ G=\operatorname{Gal}(F_0^{T,+}(2)/F_0). \]

We use the standard marked Golod–Shafarevich criterion. In the present setting it says:

Let \(K\) be a number field and \(T\) a finite set of finite primes. Let \(G_T^+(K,2)\) be the Galois group of the maximal pro-\(2\) extension of \(K\) unramified at finite primes and split at the real places and at all primes in \(T\). Let

\[ d=\dim_{\mathbb F_2}\mathrm{Cl}_T^+(K)/2\mathrm{Cl}_T^+(K), \]

where \(\mathrm{Cl}_T^+(K)\) is the narrow class group modulo the subgroup generated by the primes in \(T\). Then \(G_T^+(K,2)\) has generator rank \(d\), and its relation rank \(r\) satisfies

\[ r\le d+r_1(K)+r_2(K)+|T|+1. \]

If \(G_T^+(K,2)\) is finite, the Golod–Shafarevich inequality gives

\[ r>\frac{d^2}{4}. \]

For our real quadratic field \(F_0\), we have \(r_1(F_0)=2\), \(r_2(F_0)=0\), and \(|T|=2\). Hence the relation-rank bound is

\[ r\le d+5. \]

By genus theory for quadratic fields, since the discriminant of \(F_0\) is a product of \(t=20\) distinct positive prime discriminants, the narrow class group has \(2\)-rank

\[ \dim_{\mathbb F_2}\mathrm{Cl}^+(F_0)/2\mathrm{Cl}^+(F_0)=t-1=19. \]

Passing to the \(T\)-marked class group can reduce the \(2\)-rank by at most \(|T|=2\). Therefore

\[ d\ge 19-2=17. \]

But for \(d\ge 17\),

\[ d+5<\frac{d^2}{4}. \]

Thus \(G\) cannot be finite. Therefore \(F_0^{T,+}(2)/F_0\) is infinite.

Choose a sequence of finite subextensions

\[ F_0\subset F_1\subset F_2\subset\cdots\subset F_0^{T,+}(2) \]

with \([F_i:F_0]\to\infty\).

Each \(F_i\) is totally real because the real places split completely. Each \(F_i/F_0\) is unramified at finite primes, so the root discriminant is constant:

\[ \operatorname{rd}(F_i)=\operatorname{rd}(F_0)=m^{1/2}. \]

Finally, the two primes of \(F_0\) above \(5\) split completely in every \(F_i\). Since \(5\) already splits in \(F_0\), it follows that \(5\) splits completely in every \(F_i\).

Thus the lemma holds with

\[ p=5, \qquad \Delta=\operatorname{rd}(F_0)=m^{1/2}. \]

\(\square\)

2. A uniform class-number bound

We will later apply this to \(K_i=F_i(i)\).

Lemma 2 — Class numbers in bounded-root-discriminant families

For every \(R>0\), there exists a constant \(C_{\mathrm{cl}}(R)>0\) such that every number field \(L\) with

\[ \operatorname{rd}(L)\le R \]

satisfies

\[ h(L)\le C_{\mathrm{cl}}(R)^{[L:\mathbb Q]}. \]

Proof

Let \(n=[L:\mathbb Q]\). By Minkowski’s ideal-class theorem, every ideal class contains an integral ideal \(\mathfrak a\) with

\[ N\mathfrak a \le \left(\frac{4}{\pi}\right)^{r_2} \frac{n!}{n^n} \sqrt{|D_L|}. \]

Since \(r_2\le n/2\), \(n!/n^n\le 1\), and \(|D_L|^{1/n}\le R\), this gives

\[ N\mathfrak a \le \left(\left(\frac{4}{\pi}\right)^{1/2}R^{1/2}\right)^n. \]

Set

\[ M_R=\max\left(2,\left(\frac{4}{\pi}\right)^{1/2}R^{1/2}\right). \]

So every ideal class contains an integral ideal of norm at most \(M_R^n\).

We next bound the number of ideals of norm at most \(M_R^n\). For \(X\ge 1\),

\[ \#\{\mathfrak a\subseteq \mathcal O_L:N\mathfrak a\le X\} \le X^2\zeta_L(2). \]

Moreover,

\[ \zeta_L(2)\le \zeta(2)^n. \]

Indeed, at every rational prime \(\ell\), the Euler factor of \(\zeta_L(s)\) is at most \((1-\ell^{-s})^{-n}\).

Taking \(X=M_R^n\), we get

\[ h(L) \le M_R^{2n}\zeta(2)^n = \bigl(M_R^2\zeta(2)\bigr)^n. \]

Thus one may take

\[ C_{\mathrm{cl}}(R)=M_R^2\zeta(2). \]

\(\square\)

3. A counting lemma for denominator boxes in totally real fields

Let \(F\) be totally real of degree \(d\). For an integer \(Q\ge 1\) and \(R>0\), define

\[ A_F(R;Q) = \left\{ a\in Q^{-1}\mathcal O_F: |\tau(a)|\le R \text{ for every real embedding } \tau:F\hookrightarrow \mathbb R \right\}. \]

We will mostly use \(R=1,2\).

Lemma 3 — Box count and overlap supply

Suppose \(F\) is totally real of degree \(d\) and

\[ \operatorname{rd}(F)\le \Delta. \]

Then, for every integer \(Q\ge 1\) and every \(R>0\),

\[ |A_F(R;Q)| \ge \left(\frac{RQ}{\sqrt{\Delta}}\right)^d. \]

Also,

\[ |A_F(2;Q)| \le (4Q+3)^d. \]

Consequently,

\[ \frac{|A_F(1;Q)|}{|A_F(2;Q)|} \ge \left(\frac{1}{7\sqrt{\Delta}}\right)^d. \]

Proof

Embed \(F\) into \(\mathbb R^d\) by the Minkowski embedding

\[ \Phi:F\hookrightarrow \mathbb R^d, \qquad a\mapsto (\tau(a))_{\tau:F\hookrightarrow \mathbb R}. \]

The image of \(Q^{-1}\mathcal O_F\) is a lattice of covolume

\[ \operatorname{covol}\bigl(\Phi(Q^{-1}\mathcal O_F)\bigr) = Q^{-d}\sqrt{|D_F|} \le Q^{-d}\Delta^{d/2}. \]

Let

\[ B_R=[-R,R]^d. \]

A standard van der Corput lattice-point lower bound says that for every symmetric convex body \(K\subset \mathbb R^d\) and every lattice \(\Lambda\),

\[ |K\cap\Lambda| \ge \frac{\operatorname{vol}(K)}{2^d\operatorname{covol}(\Lambda)}. \]

For completeness, here is the short proof: averaging over a fundamental domain shows that some translate of \(\frac12K\) contains at least \(\operatorname{vol}(K)/(2^d\operatorname{covol}(\Lambda))\) lattice points; subtracting one of them from all the others produces at least that many lattice points inside \(K\).

Applying this with \(K=B_R\), whose volume is \((2R)^d\), gives

\[ |A_F(R;Q)| = |B_R\cap \Phi(Q^{-1}\mathcal O_F)| \ge \frac{(2R)^d}{2^d Q^{-d}\sqrt{|D_F|}} = \frac{(RQ)^d}{\sqrt{|D_F|}} \ge \left(\frac{RQ}{\sqrt{\Delta}}\right)^d. \]

Now we prove the upper bound for \(A_F(2;Q)\). Partition each interval \([-2,2]\) into at most \(4Q+3\) half-open intervals of length \(<1/Q\). This partitions \([-2,2]^d\) into at most \((4Q+3)^d\) boxes.

We claim each such box contains at most one point of \(\Phi(Q^{-1}\mathcal O_F)\). Indeed, suppose \(a,b\in Q^{-1}\mathcal O_F\) are distinct and lie in the same box. Then for every embedding \(\tau\),

\[ |\tau(a-b)|<\frac1Q. \]

Hence

\[ |N_{F/\mathbb Q}(a-b)| = \prod_\tau |\tau(a-b)| < Q^{-d}. \]

But \(Q(a-b)\in \mathcal O_F\) is a nonzero algebraic integer, so

\[ |N_{F/\mathbb Q}(Q(a-b))| = Q^d |N_{F/\mathbb Q}(a-b)| \]

is a positive integer. Therefore

\[ |N_{F/\mathbb Q}(a-b)|\ge Q^{-d}, \]

a contradiction. Thus each box contains at most one point, proving

\[ |A_F(2;Q)|\le (4Q+3)^d. \]

Finally,

\[ |A_F(1;Q)| \ge \left(\frac{Q}{\sqrt{\Delta}}\right)^d, \]

and

\[ |A_F(2;Q)|\le (4Q+3)^d. \]

Since \(4Q+3\le 7Q\) for \(Q\ge 1\),

\[ \frac{|A_F(1;Q)|}{|A_F(2;Q)|} \ge \left(\frac{Q}{(4Q+3)\sqrt{\Delta}}\right)^d \ge \left(\frac{1}{7\sqrt{\Delta}}\right)^d. \]

\(\square\)

4. Fixing global constants

Let \(F_i\) be the fields from Lemma 1, and put

\[ d_i=[F_i:\mathbb Q]. \]

Thus \(d_i\to\infty\), \(F_i\) is totally real, \(5\) splits completely in \(F_i\), and

\[ \operatorname{rd}(F_i)\le \Delta \]

for a fixed absolute constant \(\Delta\).

For each \(i\), set

\[ K_i=F_i(i). \]

Since \(F_i\) is totally real, \([K_i:F_i]=2\). The relative discriminant of \(K_i/F_i\) divides \(4\mathcal O_{F_i}\), so

\[ \operatorname{rd}(K_i)\le 2\operatorname{rd}(F_i)\le 2\Delta. \]

By Lemma 2, there is a constant \(C=C_{\mathrm{cl}}(2\Delta)\) such that

\[ h(K_i)\le C^{[K_i:\mathbb Q]}=C^{2d_i}. \]

Define

\[ H=C^2. \]

Then

\[ h(K_i)\le H^{d_i} \]

for all \(i\).

We now choose an integer \(E\ge 1\) so large that, with

\[ \rho=\frac{E+1}{H}, \qquad \lambda=\frac{1}{7\sqrt{\Delta}}, \]

we have

\[ \eta:=\rho\lambda^2>1. \]

This is possible because \(\rho=(E+1)/H\to\infty\) as \(E\to\infty\).

Also increase \(E\), if necessary, so that

\[ \frac{2Q}{\sqrt{\Delta}}>1, \]

where

\[ Q=2\cdot 5^{2E}. \]

Finally define

\[ B=4Q+3. \]

All constants

\[ \Delta,H,E,Q,\rho,\lambda,\eta,B \]

are now fixed once and for all, independent of \(i\).

5. Many norm-one elements in \(K_i=F_i(i)\)

Fix one of the fields \(F=F_i\), and write

\[ d=[F:\mathbb Q]. \]

Let

\[ K=F(i). \]

Because \(5\) splits completely in \(F\), we may write

\[ 5\mathcal O_F = \mathfrak q_1\mathfrak q_2\cdots \mathfrak q_d, \]

with \(N\mathfrak q_j=5\). Since \(5\equiv 1\pmod 4\), the polynomial \(X^2+1\) splits over \(\mathbb Q_5\). Therefore each \(\mathfrak q_j\) splits in \(K=F(i)\):

\[ \mathfrak q_j\mathcal O_K = \mathfrak P_j\overline{\mathfrak P}_j. \]

Here the bar denotes the nontrivial automorphism of \(K/F\), i.e. complex conjugation \(i\mapsto -i\).

For each exponent vector

\[ e=(e_1,\dots,e_d)\in \{0,1,\dots,E\}^d, \]

define the fractional ideal

\[ \mathfrak a_e = \prod_{j=1}^d \mathfrak P_j^{e_j}\overline{\mathfrak P}_j^{-e_j}. \]

Consider its ideal class \([\mathfrak a_e]\in \operatorname{Cl}(K)\).

There are \((E+1)^d\) such exponent vectors, while

\[ |\operatorname{Cl}(K)|=h(K)\le H^d. \]

Thus, by pigeonholing, there is a subset

\[ \mathcal E\subseteq \{0,1,\dots,E\}^d \]

such that all \(\mathfrak a_e\), \(e\in \mathcal E\), have the same ideal class and

\[ |\mathcal E| \ge \frac{(E+1)^d}{H^d} = \rho^d. \]

Fix one element \(e^0\in\mathcal E\). For every \(e\in\mathcal E\), put

\[ f=e-e^0\in [-E,E]^d\cap \mathbb Z^d. \]

Then

\[ \mathfrak a_f := \prod_{j=1}^d \mathfrak P_j^{f_j}\overline{\mathfrak P}_j^{-f_j} = \mathfrak a_e\mathfrak a_{e^0}^{-1} \]

is principal. Choose \(\beta_f\in K^\times\) such that

\[ (\beta_f)=\mathfrak a_f. \]

Now define

\[ \alpha_f=\frac{\beta_f}{\overline{\beta_f}}. \]

Then

\[ \alpha_f\overline{\alpha_f}=1. \]

Moreover, the valuation of \(\alpha_f\) at \(\mathfrak P_j\) is \(2f_j\). Therefore different vectors \(f\) give different elements \(\alpha_f\). Hence we have constructed a set

\[ \mathcal U_F:=\{\alpha_f:e\in\mathcal E\}\subset K^\times \]

satisfying

\[ |\mathcal U_F|\ge \rho^d. \]

For every \(\alpha\in\mathcal U_F\), write uniquely

\[ \alpha=x_\alpha+i y_\alpha \]

with \(x_\alpha,y_\alpha\in F\). Since

\[ \alpha\overline{\alpha}=1, \]

we have

\[ x_\alpha^2+y_\alpha^2=1 \]

inside \(F\).

Also, since the valuations of \(\alpha\) and \(\alpha^{-1}=\overline{\alpha}\) at all primes above \(5\) are bounded below by \(-2E\), and there are no other finite-prime denominators, we have

\[ 5^{2E}\alpha,\;5^{2E}\alpha^{-1}\in \mathcal O_K. \]

Therefore

\[ Qx_\alpha = 2\cdot 5^{2E}\cdot \frac{\alpha+\alpha^{-1}}2 = 5^{2E}(\alpha+\alpha^{-1}) \in \mathcal O_K\cap F = \mathcal O_F, \]

and similarly

\[ Qy_\alpha = 2\cdot 5^{2E}\cdot \frac{\alpha-\alpha^{-1}}{2i} = 5^{2E}\frac{\alpha-\alpha^{-1}}{i} \in \mathcal O_F. \]

Thus

\[ x_\alpha,y_\alpha\in Q^{-1}\mathcal O_F. \]

Finally, for every real embedding \(\tau:F\hookrightarrow \mathbb R\), extending \(\tau\) to \(K=F(i)\) by \(i\mapsto i\), we get

\[ |\tau(\alpha)|=1. \]

Thus

\[ |\tau(x_\alpha)|\le 1, \qquad |\tau(y_\alpha)|\le 1. \]

So for every \(\alpha\in\mathcal U_F\), we have

\[ x_\alpha,y_\alpha\in Q^{-1}\mathcal O_F, \]
\[ x_\alpha^2+y_\alpha^2=1, \]

and

\[ |\tau(x_\alpha)|,|\tau(y_\alpha)|\le 1 \]

for every real embedding \(\tau:F\hookrightarrow \mathbb R\).

6. The finite point set

For the same field \(F\), define

\[ A=A_F(2;Q) = \left\{ a\in Q^{-1}\mathcal O_F: |\tau(a)|\le 2 \text{ for all } \tau:F\hookrightarrow \mathbb R \right\}. \]

Also define the smaller box

\[ A^-:=A_F(1;Q). \]

By Lemma 3,

\[ |A|\le B^d \]

and

\[ \frac{|A^-|}{|A|} \ge \lambda^d. \]

Also,

\[ |A|\ge \left(\frac{2Q}{\sqrt{\Delta}}\right)^d, \]

and by our choice of \(E\),

\[ \frac{2Q}{\sqrt{\Delta}}>1. \]

Hence \(|A|\to\infty\) as \(d\to\infty\).

Choose one real embedding

\[ \sigma:F\hookrightarrow \mathbb R. \]

Define a finite point set

\[ P_F = \{(\sigma(a),\sigma(b)):a,b\in A\} \subset \mathbb R^2. \]

Since \(\sigma\) is injective,

\[ |P_F|=|A|^2. \]

7. Each norm-one element gives many unit distances

Fix \(\alpha\in\mathcal U_F\), and write

\[ \alpha=x_\alpha+i y_\alpha. \]

Set

\[ v_\alpha=(\sigma(x_\alpha),\sigma(y_\alpha))\in\mathbb R^2. \]

Because

\[ x_\alpha^2+y_\alpha^2=1 \]

inside \(F\), applying \(\sigma\) gives

\[ \|v_\alpha\|_2^2 = \sigma(x_\alpha)^2+\sigma(y_\alpha)^2 = 1. \]

So \(v_\alpha\) is a unit vector.

Now observe that for every \(a\in A^-\),

\[ a+x_\alpha\in A. \]

Indeed, \(a,x_\alpha\in Q^{-1}\mathcal O_F\), and for every real embedding \(\tau\),

\[ |\tau(a+x_\alpha)| \le |\tau(a)|+|\tau(x_\alpha)| \le 1+1 = 2. \]

Similarly,

\[ a+y_\alpha\in A \]

for every \(a\in A^-\).

Therefore for every pair \((a,b)\in A^-\times A^-\), both

\[ (a,b)\in A\times A \]

and

\[ (a+x_\alpha,b+y_\alpha)\in A\times A. \]

Consequently,

\[ (\sigma(a),\sigma(b)) \quad\text{and}\quad (\sigma(a+x_\alpha),\sigma(b+y_\alpha)) \]

are two points of \(P_F\) at Euclidean distance \(1\).

Thus each \(\alpha\in\mathcal U_F\) contributes at least

\[ |A^-|^2 \]

ordered unit-distance pairs.

Distinct \(\alpha\)'s give distinct translation vectors. Indeed, if

\[ (\sigma(x_\alpha),\sigma(y_\alpha)) = (\sigma(x_\beta),\sigma(y_\beta)), \]

then injectivity of \(\sigma\) gives \(x_\alpha=x_\beta\) and \(y_\alpha=y_\beta\), hence \(\alpha=\beta\).

Therefore the ordered unit-distance count satisfies

\[ 2u(P_F) \ge |\mathcal U_F|\,|A^-|^2. \]

Hence

\[ u(P_F) \ge \frac12 |\mathcal U_F|\,|A^-|^2. \]

Using

\[ |\mathcal U_F|\ge \rho^d \]

and

\[ |A^-|\ge \lambda^d |A|, \]

we get

\[ u(P_F) \ge \frac12 \rho^d\lambda^{2d}|A|^2. \]

Recall that \(|P_F|=|A|^2\). Hence

\[ u(P_F) \ge \frac12(\rho\lambda^2)^d |P_F|. \]

By definition,

\[ \eta=\rho\lambda^2>1. \]

Thus

\[ u(P_F) \ge \frac12\eta^d |P_F|. \]

8. Converting the exponential gain in \(d\) into a power gain in \(|P_F|\)

We also have

\[ |P_F|=|A|^2\le B^{2d}. \]

Set

\[ \delta = \frac{\log \eta}{4\log B}. \]

Since \(\eta>1\) and \(B>1\), we have

\[ \delta>0. \]

Then

\[ |P_F|^\delta \le (B^{2d})^\delta = B^{2\delta d} = \exp(2\delta d\log B) = \exp\left(\frac12 d\log\eta\right) = \eta^{d/2}. \]

For all sufficiently large \(d\),

\[ \frac12\eta^d\ge \eta^{d/2}. \]

Therefore, for all sufficiently large \(d\),

\[ \frac12\eta^d\ge |P_F|^\delta. \]

Plugging this into the previous estimate gives

\[ u(P_F) \ge |P_F|^{1+\delta}. \]

Finally, because

\[ |P_F|=|A|^2 \ge \left(\frac{2Q}{\sqrt{\Delta}}\right)^{2d}, \]

and

\[ \frac{2Q}{\sqrt{\Delta}}>1, \]

we have

\[ |P_F|\to\infty \]

as \(d\to\infty\).

Taking the fields \(F_i\) from Lemma 1 and discarding finitely many initial ones, we obtain an infinite sequence

\[ P_i=P_{F_i}\subset\mathbb R^2 \]

such that

\[ |P_i|\to\infty \]

and

\[ u(P_i)\ge |P_i|^{1+\delta} \]

for every \(i\).

This proves the theorem. \(\square\)

Summary of the construction

The construction is best viewed as a high-degree analogue of the classical Gaussian-integer construction.

Classically, one gets unit directions from

\[ \alpha=\frac{z}{\overline z}\in \mathbb Q(i), \qquad |\alpha|=1. \]

The number of available directions is controlled by the number of small primes splitting in \(\mathbb Z[i]\), but in \(\mathbb Q(i)\) those primes have growing rational norm, causing the usual \(n^{o(1)}\) bottleneck.

Here we instead use high-degree totally real fields \(F_i\) in which one fixed small prime, namely \(5\), splits completely. Passing to

\[ K_i=F_i(i), \]

each prime of \(F_i\) over \(5\) splits into a conjugate pair. Exponent vectors on these conjugate prime pairs produce exponentially many norm-one \(S\)-units

\[ \alpha\overline{\alpha}=1. \]

Writing

\[ \alpha=x+iy \]

gives

\[ x^2+y^2=1 \]

inside \(F_i\), hence genuine Euclidean unit vectors after applying any real embedding.

The point set is a product

\[ P_i=\sigma(A_i)\times \sigma(A_i), \]

where \(A_i\subset F_i\) is a large finite denominator box. Because every coordinate \(x,y\) of every direction has bounded denominator and all conjugates bounded by \(1\), translating \(A_i\) by \(x\) or \(y\) preserves a fixed exponential proportion of \(A_i\). Exponentially many directions times exponentially many preserved points per direction gives

\[ u(P_i)\ge |P_i|^{1+\delta} \]

for some fixed \(\delta>0\).

1. A totally real tower with a fixed split prime

We use the following standard marked Golod–Shafarevich criterion.

Lemma 1 — Marked Golod–Shafarevich criterion

Let \(k\) be a number field and let \(T\) be a finite set of finite primes of \(k\). Let \(k_T^+(2)\) be the maximal pro-\(2\) extension of \(k\) which is unramified at every finite prime and in which every real place of \(k\), and every prime in \(T\), splits completely.

Let

\[ \mathrm{Cl}_T^+(k) \]

denote the narrow class group of \(k\), modulo the subgroup generated by the classes of the primes in \(T\). Put

\[ g=\dim_{\mathbb F_2}\mathrm{Cl}_T^+(k)/2\mathrm{Cl}_T^+(k). \]

If

\[ \frac{g^2}{4}>g+r_1(k)+r_2(k)+|T|+1, \]

then \(k_T^+(2)/k\) is infinite.

Justification

By class field theory, the generator rank of

\[ G=\operatorname{Gal}(k_T^+(2)/k) \]

equals \(g\). Shafarevich’s relation-rank bound gives

\[ r(G)\le g+r_1(k)+r_2(k)+|T|+1. \]

If \(G\) were finite, the Golod–Shafarevich inequality would force

\[ r(G)>\frac{g^2}{4}. \]

The displayed inequality contradicts this. Hence \(G\) is infinite. \(\square\)

\[ \frac{g^2}{4}>g+5. \]

\[ F_0{}_T^+(2)/F_0 \]

2. Uniform class-number and lattice-counting estimates

We will use two elementary estimates.

Lemma 3 — Class numbers in bounded-root-discriminant families

For every \(R>0\), there is a constant \(C_{\mathrm{cl}}(R)\) such that every number field \(L\) with

\[ \operatorname{rd}(L)\le R \]

satisfies

\[ h(L)\le C_{\mathrm{cl}}(R)^{[L:\mathbb Q]}. \]

Proof

Let \(n=[L:\mathbb Q]\). By Minkowski’s ideal-class theorem, every ideal class contains an integral ideal of norm at most

\[ \left(\frac4\pi\right)^{r_2} \frac{n!}{n^n} \sqrt{|D_L|}. \]

Since \(r_2\le n/2\), \(n!\le n^n\), and \(|D_L|^{1/n}\le R\), every class contains an ideal of norm at most

\[ M_R^n, \qquad M_R=\max\left(2,\left(\frac4\pi\right)^{1/2}R^{1/2}\right). \]

The number of ideals of norm at most \(X\) is at most

\[ X^2\zeta_L(2). \]

Also

\[ \zeta_L(2)\le \zeta(2)^n. \]

Taking \(X=M_R^n\), we obtain

\[ h(L)\le M_R^{2n}\zeta(2)^n. \]

Thus one may take

\[ C_{\mathrm{cl}}(R)=M_R^2\zeta(2). \]

\(\square\)

Lemma 4 — Counting denominator boxes

Let \(F\) be totally real of degree \(d\), with

\[ \operatorname{rd}(F)\le \Delta. \]

For an integer \(Q\ge 1\) and \(R>0\), define

\[ A_F(R;Q)= \left\{ a\in Q^{-1}\mathcal O_F: |\tau(a)|\le R \text{ for every real embedding }\tau:F\hookrightarrow\mathbb R \right\}. \]

Then

\[ |A_F(R;Q)| \ge \left(\frac{RQ}{\sqrt{\Delta}}\right)^d, \]

and

\[ |A_F(2;Q)|\le (4Q+3)^d. \]

Consequently,

\[ \frac{|A_F(1;Q)|}{|A_F(2;Q)|} \ge \left(\frac{1}{7\sqrt{\Delta}}\right)^d. \]

Embed \(F\) into \(\mathbb R^d\) by

\[ \Phi(a)=(\tau(a))_{\tau}. \]

The image of \(Q^{-1}\mathcal O_F\) is a lattice of covolume

\[ Q^{-d}\sqrt{|D_F|} \le Q^{-d}\Delta^{d/2}. \]

\[ |B_R\cap \Phi(Q^{-1}\mathcal O_F)| \ge \frac{\operatorname{vol}(B_R)}{2^d\operatorname{covol}(\Phi(Q^{-1}\mathcal O_F))}. \]

Since \(\operatorname{vol}(B_R)=(2R)^d\), this gives

\[ |A_F(R;Q)| \ge \frac{(2R)^d}{2^d Q^{-d}\Delta^{d/2}} = \left(\frac{RQ}{\sqrt{\Delta}}\right)^d. \]

\[ |\tau(a-b)|<\frac1Q \]

for every embedding \(\tau\). Hence

\[ |N_{F/\mathbb Q}(a-b)|<Q^{-d}. \]

\[ Q^d|N_{F/\mathbb Q}(a-b)| = |N_{F/\mathbb Q}(Q(a-b))| \]

is a positive integer, contradiction.

\[ |A_F(2;Q)|\le (4Q+3)^d. \]

\[ |A_F(1;Q)| \ge \left(\frac{Q}{\sqrt{\Delta}}\right)^d, \]

while

\[ |A_F(2;Q)|\le (4Q+3)^d\le (7Q)^d. \]

Therefore

\[ \frac{|A_F(1;Q)|}{|A_F(2;Q)|} \ge \left(\frac{1}{7\sqrt{\Delta}}\right)^d. \]

\(\square\)

3. Fixing constants

Let \(F_i\) be the fields from Lemma 2. Put

\[ d_i=[F_i:\mathbb Q]. \]

For each \(i\), set

\[ K_i=F_i(\mathbf i), \qquad \mathbf i^2=-1. \]

Since \(K_i/F_i\) is generated by a root of \(X^2+1\), its relative discriminant divides \(4\mathcal O_{F_i}\). Therefore

\[ \operatorname{rd}(K_i)\le 2\operatorname{rd}(F_i)\le 2\Delta. \]

By Lemma 3, there is a constant \(C=C_{\mathrm{cl}}(2\Delta)\) such that

\[ h(K_i)\le C^{[K_i:\mathbb Q]}=C^{2d_i}. \]

Set

\[ H=C^2. \]

Then

\[ h(K_i)\le H^{d_i}. \]

Now choose an integer \(E\ge 1\) so large that, with

\[ \lambda=\frac{1}{7\sqrt{\Delta}}, \qquad \rho=\frac{E+1}{H}, \]

we have

\[ \eta:=\rho\lambda^2>1. \]

Also require

\[ \frac{2Q}{\sqrt{\Delta}}>1, \qquad Q=2\cdot 5^{2E}. \]

This is possible because \(E\) is arbitrary.

Finally put

\[ B=4Q+3. \]

All constants

\[ \Delta,H,E,Q,\lambda,\rho,\eta,B \]

are now fixed absolute constants.

4. Constructing many norm-one \(S\)-units

Fix one of the fields \(F=F_i\), and write

\[ d=[F:\mathbb Q], \qquad K=F(\mathbf i). \]

Because \(5\) splits completely in \(F\), we may write

\[ 5\mathcal O_F=\mathfrak q_1\cdots \mathfrak q_d, \qquad N\mathfrak q_j=5. \]

Since \(5\equiv 1\pmod 4\), the element \(-1\) is a square in \(\mathbb Q_5\). Hence every \(\mathfrak q_j\) splits in \(K/F\):

\[ \mathfrak q_j\mathcal O_K = \mathfrak P_j\overline{\mathfrak P}_j. \]

Here the bar denotes the nontrivial automorphism of \(K/F\), i.e. complex conjugation.

For each vector

\[ e=(e_1,\dots,e_d)\in\{0,1,\dots,E\}^d, \]

define the fractional ideal

\[ \mathfrak a_e = \prod_{j=1}^d \mathfrak P_j^{e_j}\overline{\mathfrak P}_j^{-e_j}. \]

There are \((E+1)^d\) such vectors, while

\[ h(K)\le H^d. \]

Therefore some ideal class contains at least

\[ \frac{(E+1)^d}{H^d}=\rho^d \]

of the ideals \(\mathfrak a_e\). Let \(\mathcal E\subseteq\{0,\dots,E\}^d\) be such a set, so

\[ |\mathcal E|\ge \rho^d, \]

and all \(\mathfrak a_e\), \(e\in\mathcal E\), have the same ideal class.

Fix \(e^0\in\mathcal E\). For \(e\in\mathcal E\), put

\[ f=e-e^0\in[-E,E]^d. \]

Then

\[ \mathfrak a_f:= \prod_{j=1}^d \mathfrak P_j^{f_j}\overline{\mathfrak P}_j^{-f_j} = \mathfrak a_e\mathfrak a_{e^0}^{-1} \]

is principal. Choose \(\beta_f\in K^\times\) such that

\[ (\beta_f)=\mathfrak a_f. \]

Define

\[ \alpha_f=\frac{\beta_f}{\overline{\beta_f}}. \]

Then

\[ \alpha_f\overline{\alpha_f}=1. \]

Also,

\[ (\alpha_f) = \mathfrak a_f^2. \]

Thus the valuation vector of \(\alpha_f\) at the primes \(\mathfrak P_j\) is

\[ (v_{\mathfrak P_1}(\alpha_f),\dots,v_{\mathfrak P_d}(\alpha_f)) = (2f_1,\dots,2f_d). \]

Hence distinct \(f\)’s give distinct \(\alpha_f\)’s.

Therefore the set

\[ \mathcal U_F=\{\alpha_f:e\in\mathcal E\} \]

satisfies

\[ |\mathcal U_F|\ge \rho^d. \]

5. Coordinates of the \(S\)-units

For \(\alpha\in\mathcal U_F\), write uniquely

\[ \alpha=x_\alpha+\mathbf i y_\alpha, \qquad x_\alpha,y_\alpha\in F. \]

Since

\[ \alpha\overline{\alpha}=1, \]

we have

\[ x_\alpha^2+y_\alpha^2=1. \]

The valuations of \(\alpha\) at primes above \(5\) lie between \(-2E\) and \(2E\), and \(\alpha\) has no other finite-prime denominators. Hence

\[ 5^{2E}\alpha,\;5^{2E}\alpha^{-1}\in\mathcal O_K. \]

Recall

\[ Q=2\cdot 5^{2E}. \]

Since

\[ x_\alpha=\frac{\alpha+\alpha^{-1}}2, \qquad y_\alpha=\frac{\alpha-\alpha^{-1}}{2\mathbf i}, \]

we get

\[ Qx_\alpha = 5^{2E}(\alpha+\alpha^{-1})\in \mathcal O_K\cap F=\mathcal O_F, \]

and

\[ Qy_\alpha = 5^{2E}\frac{\alpha-\alpha^{-1}}{\mathbf i} \in \mathcal O_K\cap F=\mathcal O_F. \]

Thus

\[ x_\alpha,y_\alpha\in Q^{-1}\mathcal O_F. \]

Moreover, for every real embedding \(\tau:F\hookrightarrow\mathbb R\),

\[ \tau(x_\alpha)^2+\tau(y_\alpha)^2=1, \]

so

\[ |\tau(x_\alpha)|\le 1, \qquad |\tau(y_\alpha)|\le 1. \]

6. The finite point set

Define

\[ A=A_F(2;Q) = \left\{ a\in Q^{-1}\mathcal O_F: |\tau(a)|\le 2 \text{ for all real embeddings }\tau \right\}, \]

and

\[ A^- = A_F(1;Q). \]

By Lemma 4,

\[ |A|\le B^d, \]

and

\[ \frac{|A^-|}{|A|} \ge \lambda^d. \]

Also,

\[ |A| \ge \left(\frac{2Q}{\sqrt{\Delta}}\right)^d. \]

By our choice of \(E\), the base \(2Q/\sqrt{\Delta}\) is \(>1\), so \(|A|\to\infty\) as \(d\to\infty\).

Choose one real embedding

\[ \sigma:F\hookrightarrow\mathbb R. \]

Set

\[ P_F=\{(\sigma(a),\sigma(b)):a,b\in A\}\subset\mathbb R^2. \]

Since \(\sigma\) is injective,

\[ |P_F|=|A|^2. \]

7. Counting unit distances

Fix \(\alpha\in\mathcal U_F\), and write

\[ \alpha=x_\alpha+\mathbf i y_\alpha. \]

Let

\[ v_\alpha=(\sigma(x_\alpha),\sigma(y_\alpha)). \]

Because \(x_\alpha^2+y_\alpha^2=1\), we have

\[ \|v_\alpha\|_2=1. \]

Now take any \(a,b\in A^-\). Since \(x_\alpha,y_\alpha\in Q^{-1}\mathcal O_F\), and since all their real conjugates have absolute value at most \(1\), we have

\[ a+x_\alpha\in A, \qquad b+y_\alpha\in A. \]

Indeed, for every real embedding \(\tau\),

\[ |\tau(a+x_\alpha)| \le |\tau(a)|+|\tau(x_\alpha)| \le 1+1=2, \]

and similarly for \(b+y_\alpha\).

Thus

\[ (\sigma(a),\sigma(b)), \quad (\sigma(a+x_\alpha),\sigma(b+y_\alpha)) \]

are two points of \(P_F\) separated by the unit vector \(v_\alpha\).

So each \(\alpha\in\mathcal U_F\) and each pair \((a,b)\in A^-\times A^-\) gives an ordered unit-distance pair in \(P_F\).

This assignment is injective. If two triples \((\alpha,a,b)\) and \((\alpha',a',b')\) give the same ordered pair, then equality of the first point gives

\[ a=a', \qquad b=b', \]

because \(\sigma\) is injective. Equality of the second point then gives

\[ \sigma(x_\alpha)=\sigma(x_{\alpha'}), \qquad \sigma(y_\alpha)=\sigma(y_{\alpha'}). \]

Again using injectivity of \(\sigma\), we obtain

\[ x_\alpha=x_{\alpha'}, \qquad y_\alpha=y_{\alpha'}, \]

hence

\[ \alpha=\alpha'. \]

Therefore the number of ordered unit-distance pairs in \(P_F\) is at least

\[ |\mathcal U_F|\,|A^-|^2. \]

Since \(u(P_F)\) counts unordered pairs,

\[ u(P_F)\ge \frac12|\mathcal U_F|\,|A^-|^2. \]

Using

\[ |\mathcal U_F|\ge \rho^d \]

and

\[ |A^-|\ge \lambda^d |A|, \]

we get

\[ u(P_F) \ge \frac12 \rho^d\lambda^{2d}|A|^2. \]

Since

\[ |P_F|=|A|^2 \]

and

\[ \eta=\rho\lambda^2>1, \]

this becomes

\[ u(P_F) \ge \frac12 \eta^d |P_F|. \]

8. Converting the exponential gain into a power gain

We have

\[ |P_F|=|A|^2\le B^{2d}. \]

Define

\[ \delta=\frac{\log\eta}{4\log B}>0. \]

Then

\[ |P_F|^\delta \le (B^{2d})^\delta = \eta^{d/2}. \]

For all sufficiently large \(d\),

\[ \frac12\eta^d\ge \eta^{d/2}. \]

Hence, for all sufficiently large \(d\),

\[ u(P_F) \ge |P_F|^{1+\delta}. \]

Finally,

\[ |P_F|=|A|^2 \ge \left(\frac{2Q}{\sqrt{\Delta}}\right)^{2d}, \]

and the base is \(>1\). Since the degrees \(d_i\to\infty\), we have

\[ |P_{F_i}|\to\infty. \]

Discarding finitely many initial fields and reindexing, we obtain an infinite sequence

\[ P_i\subset\mathbb R^2 \]

such that

\[ |P_i|\to\infty \]

and

\[ u(P_i)\ge |P_i|^{1+\delta} \]

for every \(i\).

This proves the theorem. \(\square\)
