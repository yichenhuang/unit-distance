Assistant

I’ll write \(\mathbb R^2\cong \mathbb C\), so a unit-distance pair is a pair whose difference lies on the unit circle

\[ \mathbb S^1=\{z\in\mathbb C: |z|=1\}. \]

A useful unifying reduction is the following.

If we can find finite sets \(A\subset \mathbb C\) and \(S\subset \mathbb S^1\) such that

\[ |A+S| \ll |A| \qquad\text{and}\qquad |S|\ge |A|^{\delta}, \]

then the set

\[ P:=A\cup (A+S) \]

has many unit distances: for every \(a\in A\) and \(s\in S\), the pair \((a,a+s)\) is a unit pair. If the representations are not too degenerate, then

\[ u(P)\gtrsim |A||S|\gtrsim |P|^{1+\delta'}. \]

So the theorem is morally about building a finite set \(A\) with small expansion by many unit directions. The three approaches below are different ways of producing such \(A,S\).

Approach 1: Build many unit directions inside a low-complexity additive module

Core idea

Construct a high-rank additive progression in \(\mathbb C\),

\[ \Lambda=\left\{\sum_{j=1}^d n_j g_j : n_j\in\mathbb Z\right\}, \]

with \(d\to\infty\), such that the unit circle contains exponentially many elements of \(\Lambda\) whose coordinates in the basis \(g_1,\dots,g_d\) are bounded by an absolute constant.

More precisely, aim to prove the following sufficient lemma.

Sufficient lemma: unit-rich bounded progression

Suppose there exist constants

\[ \alpha>1,\qquad \beta>0,\qquad C\ge 1 \]

and, for infinitely many \(r\), complex numbers \(g_1,\dots,g_d\), with \(d\le \beta r\), and a set

\[ S_r\subset \mathbb S^1 \]

such that

  1. \(|S_r|\ge \alpha^r\);

  2. every \(s\in S_r\) has a representation

    \[ s=\sum_{j=1}^d c_j(s)g_j \]

    with integers \(c_j(s)\in[-C,C]\);

  3. the map

    \[ (n_1,\dots,n_d)\mapsto \sum_{j=1}^d n_jg_j \]

    is injective on boxes of side length \(L+O(C)\), where \(L\) is some sufficiently large absolute constant.

Then the theorem follows.

Indeed, define

\[ A_r:=\left\{\sum_{j=1}^d n_jg_j: 0\le n_j<L\right\}. \]

Then

\[ |A_r|=L^d. \]

For each \(s\in S_r\), because \(s\) has bounded integer coordinates, all points in the interior box

\[ C\le n_j<L-C \]

satisfy \(a+s\in A_r\). Thus each \(s\in S_r\) contributes at least \((L-2C)^d\) unit pairs inside \(A_r\). Therefore

\[ u(A_r)\gtrsim |S_r|(L-2C)^d \ge \alpha^r (L-2C)^d. \]

Since \(d\le \beta r\), we have \(r\ge d/\beta\), so

\[ u(A_r) \gtrsim \alpha^{d/\beta}(L-2C)^d = \left(\alpha^{1/\beta}(L-2C)\right)^d. \]

Meanwhile

\[ |A_r|=L^d. \]

If \(L\) is chosen so that

\[ \alpha^{1/\beta}(L-2C)>L, \]

then

\[ u(A_r)\ge |A_r|^{1+\delta} \]

for some absolute \(\delta>0\).

So the main task is to construct, for arbitrarily large \(r\), an additive module of rank \(O(r)\) containing \(\alpha^r\) distinct unit vectors of bounded coordinate complexity.

Function-field source of exponentially many unit directions

The classical Erdős lower bound uses Gaussian integers. One chooses an integer \(R\) with many representations

\[ a^2+b^2=R^2, \]

so that the vectors

\[ \frac{a+ib}{R} \]

are unit vectors. The limitation is that an integer \(R\) cannot have polynomially many essentially different Gaussian divisors; one only gets \(R^{o(1)}\) directions.

A natural way around this is to move first to a function field. Let

\[ \ell_j(t)=t-z_j,\qquad \overline{\ell_j}(t)=t-\overline{z_j} \]

with \(z_j\in\mathbb C\setminus\mathbb R\). For every choice of signs \(\varepsilon=(\varepsilon_1,\dots,\varepsilon_r)\in\{\pm1\}^r\), define

\[ G_\varepsilon(t) = \prod_{j=1}^r \begin{cases} \ell_j(t), & \varepsilon_j=1,\\ \overline{\ell_j}(t), & \varepsilon_j=-1. \end{cases} \]

For real \(t=T\), the ratio

\[ u_\varepsilon(T) := \frac{G_\varepsilon(T)} {\overline{G_\varepsilon(T)}} \]

has modulus \(1\). Thus

\[ u_\varepsilon(T)\in \mathbb S^1. \]

There are \(2^r\) such directions. This is the function-field analogue of having \(2^r\) Gaussian divisors.

To put the directions over a common denominator, write

\[ D(t):=\prod_{j=1}^r \overline{\ell_j}(t). \]

Then each \(u_\varepsilon(t)\) can be written as

\[ u_\varepsilon(t)=\frac{N_\varepsilon(t)}{D(t)} \]

where \(N_\varepsilon(t)\) is a polynomial of degree at most \(r\). The real vector space of possible numerators has dimension \(O(r)\). Thus the \(2^r\) unit directions all live in an \(O(r)\)-dimensional real vector space after specialization \(t=T\).

The remaining challenge is additive-combinatorial: choose \(z_1,\dots,z_r\) and \(T\) so that the \(2^r\) values \(u_\varepsilon(T)\) lie in an actual rank-\(O(r)\) additive lattice with bounded coordinate complexity.

A concrete technical target would be:

Bounded divisor basis lemma. There exist choices of \(z_1,\dots,z_r\) and a real specialization \(T\) for which the \(2^r\) unit complex numbers \(u_\varepsilon(T)\) are distinct and lie in a generalized arithmetic progression of rank \(O(r)\) and volume \(\exp(O(r))\).

Once that lemma is proved, the sufficient lemma above gives the theorem immediately.

Why this approach is promising

This is the most direct continuation of Erdős’s original construction. The obstruction in the integer/Gaussian-integer setting is the divisor bound: an integer of size \(R\) has only \(R^{o(1)}\) Gaussian divisors. In a polynomial ring, however, a degree-\(r\) polynomial can have \(2^r\) divisors of comparable degree. So the function-field world naturally supplies exponentially many exact unit directions.

The key is to specialize back to the real plane while keeping additive complexity linear in \(r\). If this can be done, one gets a point set of size roughly \(L^{O(r)}\) and about \(2^r\) available unit directions, hence

\[ u(P)\ge |P|^{1+\delta} \]

for some constant \(\delta>0\).

Main subproblems

  1. Bounded-coordinate specialization. Find a basis in which all \(u_\varepsilon(T)\) have bounded integer coordinates.

  2. Noncollision. Ensure the \(2^r\) directions remain distinct after specialization.

  3. Injectivity of the point progression. Ensure that the additive map from the coefficient box into \(\mathbb C\) has no unwanted collisions.

  4. Control of coefficient growth. Avoid the monomial-basis coefficient explosion that would otherwise make the progression volume \(\exp(\Theta(r^2))\) instead of \(\exp(O(r))\).

I would try to attack this using a CRT-type basis for the quotient ring generated by the factors \(\ell_j,\overline{\ell_j}\), rather than the monomial basis.

Approach 2: Degenerate unit circles to translated parabolas and lift a sharp incidence construction

Core idea

Locally, a unit circle looks like a parabola. More importantly, the incidence relation between points and unit circles degenerates exactly to the incidence relation between points and translates of a parabola. Translated parabolas have a clean \(N^{4/3}\)-incidence construction. If enough of that construction can be lifted from the parabolic limit back to genuine unit circles, the theorem follows, even with the optimal exponent \(\delta=1/3\).

The parabolic scaling

Let centers and points have the form

\[ c=(\varepsilon a,\varepsilon^2 b), \]

and

\[ q=(\varepsilon x,1+\varepsilon^2 y), \]

where \(\varepsilon>0\) is small. Then

\[ \|q-c\|^2 = \varepsilon^2(x-a)^2+ \left(1+\varepsilon^2(y-b)\right)^2. \]

The equation \(\|q-c\|=1\) becomes

\[ \varepsilon^2(x-a)^2+ \left(1+\varepsilon^2(y-b)\right)^2=1. \]

Expanding,

\[ 1+\varepsilon^2\bigl((x-a)^2+2(y-b)\bigr) +\varepsilon^4(y-b)^2 = 1. \]

Thus

\[ (x-a)^2+2(y-b)+\varepsilon^2(y-b)^2=0. \]

When \(\varepsilon=0\), this is the translated parabola relation

\[ y=b-\frac{(x-a)^2}{2}. \]

For \(\varepsilon>0\), solving for \(y-b\) gives the exact unit-circle branch

\[ y-b=f_\varepsilon(x-a), \]

where

\[ f_\varepsilon(d) = \frac{-1+\sqrt{1-\varepsilon^2d^2}}{\varepsilon^2}. \]

As \(\varepsilon\to 0\),

\[ f_\varepsilon(d) = -\frac{d^2}{2} -\frac{\varepsilon^2 d^4}{8} -\frac{\varepsilon^4 d^6}{16} -\cdots. \]

So the unit-circle incidence geometry is an analytic perturbation of the translated-parabola incidence geometry.

Sharp incidence construction for translated parabolas

At \(\varepsilon=0\), take

\[ A=\{1,\dots,L\}, \qquad D=\{1,\dots,L\}, \qquad B=\{1,\dots,L^2\}. \]

Let the centers be indexed by \((a,b)\in A\times B\), so there are

\[ |A||B|\sim L^3 \]

centers.

For each \(d\in D\), define

\[ x=a+d, \qquad y=b-\frac{d^2}{2}. \]

The \(x\)-coordinates lie in \(A+D\), which has size \(O(L)\). The \(y\)-coordinates lie in

\[ B-\frac{D^2}{2}, \]

which has size \(O(L^2)\). Hence the number of points is also \(O(L^3)\).

But for every triple \((a,b,d)\in A\times B\times D\), we get an incidence. Therefore the number of incidences is

\[ |A||B||D|\sim L^4. \]

Thus for translated parabolas one has

\[ N\sim L^3,\qquad I\sim L^4=N^{4/3}. \]

If this incidence pattern can be lifted to unit circles, then with \(P=C\cup Q\) we get

\[ u(P)\gtrsim |P|^{4/3}. \]

That would give the theorem with \(\delta=1/3\), the largest possible exponent compatible with the Szemerédi–Trotter unit-circle incidence upper bound.

Direct lifting target

The direct analogue for unit circles is to find sets \(A,D,B\) such that

\[ |A|\sim L,\qquad |D|\sim L,\qquad |B|\sim L^2, \]

and

\[ |A+D|\ll L, \]

while also

\[ |B+f_\varepsilon(D)|\ll L^2. \]

Then define

\[ C=\{(\varepsilon a,\varepsilon^2 b): a\in A,\ b\in B\} \]

and

\[ Q=\{(\varepsilon x,1+\varepsilon^2 y): x\in A+D,\ y\in B+f_\varepsilon(D)\}. \]

For every \(a\in A\), \(b\in B\), \(d\in D\), the point

\[ q=(\varepsilon(a+d),1+\varepsilon^2(b+f_\varepsilon(d))) \]

is at distance \(1\) from

\[ c=(\varepsilon a,\varepsilon^2 b). \]

Thus we get

\[ |A||B||D|\sim L^4 \]

unit distances, while

\[ |C|+|Q|\ll L^3. \]

The hard part is to arrange the exact small-sumset condition

\[ |B+f_\varepsilon(D)|\ll L^2. \]

For \(f_0(d)=-d^2/2\), this is easy because \(d^2\in[1,L^2]\) when \(d\in[1,L]\). For \(\varepsilon>0\), the higher-order terms destroy this simple arithmetic structure. So one needs to choose \(D\) and \(\varepsilon\) more carefully.

A concrete lemma to aim for is:

Circularized parabola lemma. For infinitely many \(L\), there exist \(\varepsilon=\varepsilon_L>0\), sets \(A,D,B\subset\mathbb R\), with \(|A|\asymp |D|\asymp L\), \(|B|\asymp L^2\), such that

\[ |A+D|\ll L \]

and

\[ |B+f_{\varepsilon}(D)|\ll L^2. \]

This lemma would immediately prove the theorem.

Alternative: formal deformation of the incidence graph

Instead of preserving the product structure \(A\times B\times D\), one could attempt to lift a large subgraph of the parabolic incidence graph by formal deformation.

At \(\varepsilon=0\), we have an explicit realization with \(N\sim L^3\) vertices and \(L^4\) incidences. For \(\varepsilon>0\), the equations become analytic perturbations:

\[ (x-a)^2+2(y-b)+\varepsilon^2(y-b)^2=0. \]

One can try to choose a large subgraph \(H_L\) of the parabolic incidence graph and solve the unit-circle equations as Puiseux series in \(\varepsilon\). If this can be done to all orders, then Artin approximation or Tarski transfer gives an honest real realization for sufficiently small positive \(\varepsilon\).

Even if one loses many incidences, it is enough to preserve

\[ L^{3+\eta} \]

incidences for some fixed \(\eta>0\), because the number of vertices is \(O(L^3)\), giving

\[ u(P)\gtrsim |P|^{1+\eta/3}. \]

Thus a much weaker lifting than the full \(L^4\)-incidence construction would already prove the theorem.

Why this approach is promising

This approach starts from an explicit, sharp, real incidence construction. It does not need finite fields or complex realizations. The geometry is also extremely natural: unit circles really do degenerate to translated parabolas under the scaling above.

The main issue is exactness. Approximate parabola incidences are easy; exact unit-circle incidences require controlling the higher-order terms in \(f_\varepsilon\). Still, because only a polynomial improvement over linear is required, one may be able to keep a sufficiently large subconfiguration.

Main subproblems

  1. Find \(D\) with simultaneous additive structure for \(d\) and \(f_\varepsilon(d)\). Need both \(A+D\) and \(B+f_\varepsilon(D)\) small.

  2. Develop a formal deformation theory for incidence graphs. Identify large subgraphs of the parabolic construction whose obstruction groups vanish.

  3. Prevent splitting of coincident parabolic points. At \(\varepsilon=0\), many incidences are compressed because different triples \((a,b,d)\) yield the same point. Under perturbation these points tend to split. One must preserve enough coincidences.

  4. Use sparse subgraphs if necessary. Retaining \(L^{3+\eta}\) incidences is sufficient.

Approach 3: Transfer dense finite-field unit-distance configurations to the real plane

Core idea

Over a finite field \(\mathbb F_q\), the unit-distance graph in \(\mathbb F_q^2\) is extremely dense.

Define a graph \(G_q\) on \(\mathbb F_q^2\) by connecting \(p,q\) whenever

\[ (p_1-q_1)^2+(p_2-q_2)^2=1. \]

The equation

\[ x^2+y^2=1 \]

has \(q+O(1)\) solutions over \(\mathbb F_q\), so \(G_q\) has

\[ n=q^2 \]

vertices and degree about \(q\). Hence

\[ e(G_q)\sim q^3=n^{3/2}. \]

This is much denser than what is possible over \(\mathbb R\), where the unit-distance upper bound is \(O(n^{4/3})\). Therefore one should not try to transfer the entire finite-field graph. Instead, one should transfer a subgraph with \(N\) vertices and \(N^{1+\eta}\) edges, where \(\eta\le 1/3\).

For example, finite-field pseudorandomness suggests that one can find subgraphs with

\[ E\sim N^{4/3} \]

for suitable \(N\).

If such a finite-field subgraph can be realized as a real unit-distance graph, the theorem follows.

Algebraic formulation

Given a finite graph \(H=(V,E)\), ask whether there exist real variables

\[ (x_v,y_v)_{v\in V} \]

such that

\[ (x_v-x_w)^2+(y_v-y_w)^2=1 \]

for every edge \(vw\in E\), and such that distinct vertices are mapped to distinct points.

This is a system of polynomial equations and inequalities.

Finite-field unit graphs provide many large graphs \(H\) for which the same polynomial equations have solutions over \(\mathbb F_q\). The goal is to choose \(H\) so that the system also has a real solution.

Possible transfer mechanisms

1. Ultraproduct/Lefschetz route

Take an ultraproduct of finite fields \(\mathbb F_{q_i}\) with \(q_i\to\infty\). The resulting field has characteristic \(0\). The finite-field unit-distance relation survives in the ultraproduct.

One can then attempt to extract finite subgraphs \(H_i\) of increasing size and density whose unit-distance equations have solutions in a characteristic-zero field. By algebraic-geometry transfer principles, a polynomial system over \(\mathbb Q\) that has a solution in some characteristic-zero field has a solution over \(\mathbb C\).

The remaining step is a realification lemma:

Realification lemma. If a sufficiently sparse but still superlinear unit-distance graph has a complex realization by the equations

\[ (x_v-x_w)^2+(y_v-y_w)^2=1, \]

then it has an injective real Euclidean realization, perhaps after passing to a large subgraph.

This is the hardest part of the transfer route, because complex quadratic distance is not the same as real Euclidean distance.

2. \(p\)-adic lifting and real specialization

For a finite-field solution over \(\mathbb F_p\), try to lift the coordinates to \(\mathbb Q_p\) using Hensel-type arguments. Then use Hilbert irreducibility, weak approximation, or real-specialization methods to move the lifted solution to a number field with a real embedding.

The dream statement is:

Local-to-real lifting lemma. For a carefully chosen family of finite-field unit-distance subgraphs \(H\), solvability of the unit-distance equations over many finite fields implies solvability over a real closed field, hence over \(\mathbb R\).

Because the equations are quadratic and all edge lengths are the same, this might be more tractable than arbitrary polynomial systems.

3. Flow/cycle lifting via edge directions

Orient the graph \(H\). A unit-distance realization is equivalent to assigning to every oriented edge \(e\) a unit vector \(u_e\in \mathbb S^1\) such that around every cycle,

\[ \sum_{e\in C} \pm u_e=0. \]

Over \(\mathbb F_q\), one has many such assignments with \(u_e\in\{(x,y):x^2+y^2=1\}\).

The transfer problem becomes:

Can one choose a dense finite-field subgraph whose cycle relations can be lifted to real unit vectors?

This turns the problem into a mixture of matroid theory and additive geometry on the unit circle. One might try to choose subgraphs whose cycle space has a totally unimodular or otherwise controlled structure, allowing finite-field solutions to be lifted to real solutions.

Why this approach is promising

Finite fields naturally contain dense unit-distance graphs. Their combinatorics already has the right local structure: two unit circles meet in at most two points, just as over the reals. Thus finite-field unit graphs resemble extremal point-unit-circle incidence configurations.

If one can transfer even a small polynomial fraction of their density to the real plane, the theorem follows.

Main subproblems

  1. Choose the right finite-field subgraphs. The full graph is too dense to transfer to \(\mathbb R\), because real unit-distance graphs satisfy \(u(P)=O(n^{4/3})\). One should prune to density \(N^{1+\eta}\), ideally \(N^{4/3}\).

  2. Ensure characteristic-zero solvability. A solution over one finite field does not by itself imply a complex or real solution. One needs a uniform family or an ultraproduct/compactness argument.

  3. Realify complex solutions. Complex distance realizations may not be real Euclidean realizations. One needs a mechanism forcing or extracting real solutions.

  4. Preserve injectivity. Vertices must remain distinct after lifting.

Ranking

1. Most promising: Approach 1 — low-complexity additive module / function-field Gaussian-divisor construction

This is the route I would prioritize.

It is closest to Erdős’s original construction, but it attacks the precise bottleneck: integer divisor counts are too small, whereas function-field divisor counts are exponential in the degree. The whole theorem reduces to a clean additive-combinatorial statement: find exponentially many unit directions inside a bounded-coordinate rank-\(O(r)\) progression.

The proof would be very short once the unit-rich bounded progression lemma is established.

The key technical challenge is controlling additive complexity after specializing the function-field directions to \(\mathbb R^2\). But the presence of \(2^r\) exact norm-one rational functions in an \(O(r)\)-dimensional function space is a strong structural starting point.

2. Second most promising: Approach 2 — parabolic degeneration and incidence lifting

This approach is geometrically natural and starts from a fully explicit \(N^{4/3}\)-incidence construction for translated parabolas. The unit-circle relation is an exact analytic perturbation of that parabola relation under a simple scaling.

If one can lift even a sparse superlinear portion of the parabolic incidence graph, the theorem follows. The full lift would give the optimal exponent \(\delta=1/3\).

The main obstacle is that the high-incidence parabola construction relies on exact arithmetic coincidences involving \(d^2\), and those coincidences tend to split under the circular perturbation. Still, because one only needs some fixed \(\delta>0\), a partial deformation may be enough.

3. Third most promising: Approach 3 — finite-field transfer

Finite fields contain extremely dense unit-distance graphs, so they are an abundant source of candidate incidence patterns. This makes the approach conceptually attractive.

However, the transfer to the real Euclidean plane is a major obstacle. One must prune the finite-field graph to avoid violating the real \(O(n^{4/3})\) upper bound, then lift a finite-field polynomial solution to a real one while preserving unit distances and injectivity. The complex-to-real step is especially delicate.

I would keep this as a parallel strategy, especially because finite-field configurations often reveal the correct algebraic structure, but I would not make it the first line of attack unless a strong realification lemma becomes available.

Below is a complete proof following the spirit of the top-ranked “low-complexity additive module” approach, but with an important adaptation.

The original plan was to find exponentially many unit directions inside a rank-\(O(r)\) additive progression. The cleanest rigorous way to achieve the same effect is to use relative norm-one units in mixed-signature quadratic extensions. These units give exponentially many exact unit complex numbers under one chosen embedding. Their additive sumsets remain small because of a simple algebraic norm-separation argument.

I will identify \(\mathbb R^2\) with \(\mathbb C\).

1. Arithmetic source of many unit directions

We need the following proposition.

Proposition 1: exponentially many bounded algebraic unit directions

There exist constants

\[ \alpha>1,\qquad M\ge 1, \]

and an infinite sequence of number fields \(L_i\), embeddings

\[ \sigma_i:L_i\hookrightarrow \mathbb C, \]

and finite sets

\[ U_i\subset \mathcal O_{L_i}^{\times}, \]

such that, writing

\[ d_i=[L_i:\mathbb Q]\to\infty, \]

we have:

  1. \(|U_i|\ge \alpha^{d_i}\);

  2. for every \(u\in U_i\),

    \[ |\sigma_i(u)|=1; \]

  3. for every embedding \(\tau:L_i\hookrightarrow \mathbb C\) and every \(u\in U_i\),

    \[ |\tau(u)|\le M. \]

Thus each \(U_i\) gives exponentially many algebraic integers whose distinguished complex embeddings are exact unit complex numbers and whose other conjugates are uniformly bounded.

We first prove this proposition.

1.1. Mixed-signature quadratic towers

We use a classical theorem of Golod–Shafarevich–Martinet:

Martinet tower theorem. There exists a totally real number field \(F_0\) admitting an infinite tower of totally real extensions

\[ F_0\subset F_1\subset F_2\subset\cdots \]

with \([F_i:F_0]\to\infty\), such that the root discriminants of the \(F_i\) are uniformly bounded.

Equivalently, there is a constant \(\Delta_F\) such that

\[ |\operatorname{Disc}(F_i)|^{1/[F_i:\mathbb Q]}\le \Delta_F \]

for all \(i\).

Choose an algebraic integer \(\theta\in \mathcal O_{F_0}\) with mixed signs at the real embeddings of \(F_0\): at least one real embedding sends \(\theta\) to a positive number, and at least one real embedding sends \(\theta\) to a negative number. Such a \(\theta\) exists by weak approximation.

Define

\[ L_i:=F_i(\sqrt{\theta}). \]

Because \(\theta\) is negative at some real place of \(F_i\), it is not a square in \(F_i\), so

\[ [L_i:F_i]=2. \]

Let

\[ \rho_i:L_i\to L_i \]

be the nontrivial \(F_i\)-automorphism, so

\[ \rho_i(\sqrt{\theta})=-\sqrt{\theta}. \]

At a real place \(v\) of \(F_i\),

  • if \(v(\theta)>0\), then \(L_i\otimes_{F_i,v}\mathbb R\cong \mathbb R\times \mathbb R\);
  • if \(v(\theta)<0\), then \(L_i\otimes_{F_i,v}\mathbb R\cong \mathbb C\).

Since \(\theta\) has both positive and negative signs at the base field \(F_0\), the fields \(L_i\) have both real places and complex places, and the number of split real places is a positive proportion of \([L_i:\mathbb Q]\).

Let

\[ d_i=[L_i:\mathbb Q]. \]

Let \(s_i\) denote the number of real places of \(F_i\) that split in \(L_i\), i.e. the number of real places \(v\) of \(F_i\) with \(v(\theta)>0\). Then there is a constant

\[ \kappa>0 \]

such that

\[ s_i\ge \kappa d_i \]

for all \(i\).

Also, because the relative discriminant of \(L_i/F_i\) divides the extension of the fixed ideal \((4\theta)\subset \mathcal O_{F_0}\), the fields \(L_i\) also have uniformly bounded root discriminant. Thus there is a constant \(\Delta_L\) such that

\[ |\operatorname{Disc}(L_i)|^{1/d_i}\le \Delta_L \]

for all \(i\).

Choose one real place of \(F_0\) at which \(\theta<0\), and for each \(i\) choose a complex embedding

\[ \sigma_i:L_i\hookrightarrow \mathbb C \]

lying above a real place of \(F_i\) above that chosen negative place. Then

\[ \sigma_i\circ \rho_i=\overline{\sigma_i}. \]

1.2. Relative norm-one units

Define the relative norm-one unit group

\[ E_i^1:=\{u\in \mathcal O_{L_i}^{\times}:u\rho_i(u)=1\}. \]

Equivalently,

\[ E_i^1=\ker\left(N_{L_i/F_i}:\mathcal O_{L_i}^{\times}\to \mathcal O_{F_i}^{\times}\right). \]

At the distinguished complex embedding \(\sigma_i\), every \(u\in E_i^1\) satisfies

\[ \sigma_i(u)\overline{\sigma_i(u)} = \sigma_i(u)\sigma_i(\rho_i(u)) = \sigma_i(u\rho_i(u)) = 1. \]

Therefore

\[ |\sigma_i(u)|=1. \]

So relative norm-one units give exact unit directions.

Now consider the split real places of \(F_i\). For each split real place \(v\), choose one of the two real embeddings

\[ \tau_v:L_i\hookrightarrow \mathbb R \]

above \(v\). Since \(v\) splits, the other embedding is \(\tau_v\circ \rho_i\). For \(u\in E_i^1\),

\[ \tau_v(u)\cdot \tau_v(\rho_i(u))=1, \]

so if we define

\[ \ell_v(u):=\log|\tau_v(u)|, \]

then the other embedding contributes \(-\ell_v(u)\).

Define the relative logarithmic embedding

\[ \ell_i:E_i^1\to \mathbb R^{s_i} \]

by

\[ \ell_i(u)=(\ell_v(u))_{v}. \]

By Dirichlet’s unit theorem, \(\ell_i(E_i^1)\) is a lattice of rank \(s_i\) in \(\mathbb R^{s_i}\), up to a finite kernel consisting of roots of unity.

Let

\[ \Lambda_i:=\ell_i(E_i^1). \]

We need a uniform upper bound on the covolume of \(\Lambda_i\).

Because the root discriminants of the \(L_i\) are bounded, the analytic class number formula together with the standard residue bound for Dedekind zeta-functions gives

\[ R_{L_i}\le C_1^{d_i} \]

for some absolute constant \(C_1\), where \(R_{L_i}\) is the ordinary regulator of \(L_i\).

The relative regulator of \(L_i/F_i\), i.e. the covolume of \(\Lambda_i\), is bounded by the ordinary regulator up to an exponential-in-degree factor. Indeed, the subgroup

\[ \mathcal O_{F_i}^{\times}\cdot E_i^1\subseteq \mathcal O_{L_i}^{\times} \]

has index at most \(2^{O(d_i)}\), because for every \(u\in \mathcal O_{L_i}^{\times}\),

\[ u^2=N_{L_i/F_i}(u)\cdot \frac{u}{\rho_i(u)}, \]

where \(N_{L_i/F_i}(u)\in \mathcal O_{F_i}^{\times}\) and \(u/\rho_i(u)\in E_i^1\). Therefore the quotient is killed by \(2\).

It follows that there is a constant \(R_0\ge 1\) such that

\[ \operatorname{covol}(\Lambda_i)\le R_0^{d_i} \]

for all \(i\).

1.3. Many relative units in a bounded log box

Fix \(T>1\), to be chosen large enough later. Let

\[ Q_T=[-T,T]^{s_i}\subset \mathbb R^{s_i}. \]

We claim that \(\Lambda_i\cap Q_T\) contains exponentially many points.

A standard Blichfeldt argument gives this cleanly. Let

\[ Q_T'=[-T/2,T/2]^{s_i}. \]

Some translate of \(Q_T'\) contains at least

\[ \frac{\operatorname{vol}(Q_T')}{\operatorname{covol}(\Lambda_i)} = \frac{T^{s_i}}{\operatorname{covol}(\Lambda_i)} \]

points of \(\Lambda_i\). Subtracting one of those points from all the others, we obtain at least the same number, up to harmless constants, of lattice points in

\[ Q_T'-Q_T'=Q_T. \]

Thus

\[ |\Lambda_i\cap Q_T| \ge \frac{T^{s_i}}{2R_0^{d_i}} \]

for all sufficiently large \(i\).

Since \(s_i\ge \kappa d_i\),

\[ |\Lambda_i\cap Q_T| \ge \frac12\left(\frac{T^{\kappa}}{R_0}\right)^{d_i}. \]

Choose \(T\) so large that

\[ \alpha:=\frac12\frac{T^{\kappa}}{R_0}>1. \]

Let

\[ M:=e^T. \]

Define

\[ U_i:=\{u\in E_i^1:\|\ell_i(u)\|_{\infty}\le T\}. \]

Then

\[ |U_i|\ge \alpha^{d_i}. \]

Moreover, for every \(u\in U_i\),

  • at the distinguished complex embedding \(\sigma_i\),
\[ |\sigma_i(u)|=1; \]
  • at every complex place lying above a negative real place of \(F_i\), the same norm-one argument gives modulus \(1\);
  • at each split real place, both real embeddings have absolute value between \(e^{-T}\) and \(e^T\).

Therefore, for every embedding \(\tau:L_i\hookrightarrow \mathbb C\),

\[ |\tau(u)|\le e^T=M. \]

This proves Proposition 1.

2. A sumset construction from the unit directions

We now prove the theorem using the sets \(U_i\) from Proposition 1.

Fix one of the fields \(L=L_i\), embedding \(\sigma=\sigma_i\), degree \(d=d_i\), and unit set \(U=U_i\). Write

\[ m:=|U|. \]

Then

\[ m\ge \alpha^d. \]

For \(k\ge 1\), define the \(k\)-fold additive sumset

\[ kU:=\{u_1+\cdots+u_k:u_1,\dots,u_k\in U\}\subset \mathcal O_L. \]

The key point is that although \(U\) is exponentially large, the sumsets \(kU\) are still only exponentially large in \(d\), for fixed \(k\). This is where algebraic norm-separation replaces the bounded-coordinate progression from the original brainstorm.

Lemma 2: packing bound for \(kU\)

For each fixed \(k\ge 1\),

\[ |kU|\le (CkM)^d \]

for an absolute constant \(C\).

Proof

Let \(x,y\in kU\) be distinct. Then

\[ z:=x-y \]

is a nonzero algebraic integer.

Let

\[ r:=|\sigma(z)|. \]

Since \(z\neq 0\),

\[ N_{L/\mathbb Q}(z) \]

is a nonzero integer, so

\[ |N_{L/\mathbb Q}(z)|\ge 1. \]

Enumerate all embeddings \(\tau:L\hookrightarrow \mathbb C\). The embeddings \(\sigma\) and \(\overline{\sigma}\) contribute

\[ |\sigma(z)|\cdot |\overline{\sigma}(z)|=r^2. \]

For every other embedding \(\tau\), since each \(u\in U\) satisfies \(|\tau(u)|\le M\), every \(x\in kU\) satisfies

\[ |\tau(x)|\le kM. \]

Therefore

\[ |\tau(z)|\le 2kM. \]

Hence

\[ 1 \le |N_{L/\mathbb Q}(z)| = \prod_{\tau:L\hookrightarrow \mathbb C}|\tau(z)| \le r^2(2kM)^{d-2}. \]

Thus

\[ r\ge (2kM)^{-(d-2)/2}. \]

So distinct points of \(\sigma(kU)\subset \mathbb C\) are separated by at least

\[ \rho:=(2kM)^{-(d-2)/2}. \]

On the other hand, since \(|\sigma(u)|=1\) for all \(u\in U\), every point of \(\sigma(kU)\) lies in the disk of radius \(k\) centered at \(0\).

A packing argument in the plane gives

\[ |kU| = |\sigma(kU)| \le \left(\frac{5k}{\rho}\right)^2 \le 25k^2(2kM)^{d-2}. \]

Absorbing the harmless polynomial factor into the exponential base, we get

\[ |kU|\le (CkM)^d \]

for an absolute constant \(C\). ∎

3. Choosing a sumset with small additive growth

Let \(K\ge 2\) be a fixed integer to be chosen later. Set

\[ B:=CKM. \]

By Lemma 2,

\[ |KU|\le B^d. \]

Since

\[ |U|\ge \alpha^d, \]

we have

\[ \frac{|KU|}{|U|} \le \left(\frac{B}{\alpha}\right)^d. \]

For \(j=2,\dots,K\), define

\[ a_j:=|jU|. \]

Because \(1\in U\), the sequence \(|jU|\) is nondecreasing: adding \(1\) gives an injection

\[ jU\hookrightarrow (j+1)U. \]

Thus

\[ \prod_{j=2}^{K}\frac{|jU|}{|(j-1)U|} = \frac{|KU|}{|U|} \le \left(\frac{B}{\alpha}\right)^d. \]

Hence there exists some

\[ j\in\{2,\dots,K\} \]

such that

\[ \frac{|jU|}{|(j-1)U|} \le \exp(\varepsilon d), \]

where

\[ \varepsilon:= \frac{\log B-\log \alpha}{K-1}. \]

Since

\[ \log B=\log(CM)+\log K, \]

we have

\[ \varepsilon\to 0 \]

as \(K\to\infty\). Choose \(K\) once and for all so large that

\[ \varepsilon<\frac12\log \alpha. \]

Set

\[ \lambda:=\log\alpha-\varepsilon>0. \]

For this \(j\), define

\[ A:=(j-1)U, \qquad Q:=jU. \]

Then

\[ |Q|\le e^{\varepsilon d}|A|. \]

4. Constructing the point set

Define a finite point set in the plane by

\[ P:=\sigma(A\cup Q)\subset \mathbb C\cong \mathbb R^2. \]

Because \(\sigma\) is an embedding, it is injective, so

\[ |P|=|A\cup Q|. \]

Let

\[ n:=|P|. \]

We have

\[ n \le |A|+|Q| \le (1+e^{\varepsilon d})|A| \le 2e^{\varepsilon d}|A|. \]

Also, since \(j\le K\),

\[ |Q|\le |KU|\le B^d, \]

and hence

\[ n\le 2B^d. \]

Now consider all pairs

\[ (a,u)\in A\times U. \]

Since \(a\in (j-1)U\) and \(u\in U\), we have

\[ a+u\in jU=Q. \]

Therefore both

\[ \sigma(a),\qquad \sigma(a+u) \]

belong to \(P\). Moreover,

\[ |\sigma(a+u)-\sigma(a)| = |\sigma(u)| = 1. \]

Thus every \((a,u)\in A\times U\) produces a unit-distance pair in \(P\).

The map

\[ (a,u)\mapsto \bigl(\sigma(a),\sigma(a+u)\bigr) \]

is injective as a map into ordered pairs. Indeed, if

\[ \sigma(a)=\sigma(a') \]

then \(a=a'\), and then

\[ \sigma(a+u)=\sigma(a+u') \]

implies \(u=u'\).

Therefore there are at least

\[ |A||U| \]

ordered unit-distance pairs of this form. Since an unordered edge gives at most two ordered pairs,

\[ u(P)\ge \frac12 |A||U|. \]

Using

\[ |U|\ge \alpha^d \]

and

\[ |A|\ge \frac12 e^{-\varepsilon d}n, \]

we get

\[ u(P) \ge \frac12 |A||U| \ge \frac14 n e^{-\varepsilon d}\alpha^d = \frac14 n e^{(\log\alpha-\varepsilon)d}. \]

Thus

\[ u(P)\ge \frac14 n e^{\lambda d}. \]

Since

\[ n\le 2B^d, \]

we have

\[ e^{\lambda d} \ge \left(\frac{n}{2}\right)^{\lambda/\log B}. \]

Hence

\[ u(P) \ge c\, n^{1+\lambda/\log B} \]

for some constant \(c>0\) independent of \(i\).

Let

\[ \delta_0:=\frac{\lambda}{\log B}>0. \]

Then

\[ u(P)\ge c\, n^{1+\delta_0}. \]

Since \(d_i\to\infty\) and

\[ |U_i|\ge \alpha^{d_i}, \]

we have

\[ |P_i|\to\infty. \]

Discarding finitely many initial terms if necessary, we may absorb the constant \(c\) into the exponent. Namely, for all sufficiently large \(i\),

\[ c\, |P_i|^{1+\delta_0} \ge |P_i|^{1+\delta_0/2}. \]

Set

\[ \delta:=\frac{\delta_0}{2}>0. \]

Then for infinitely many \(i\),

\[ u(P_i)\ge |P_i|^{1+\delta}. \]

This proves the theorem. ∎

5. Summary of the construction

The proof can be summarized as follows.

  1. Choose mixed-signature quadratic extensions \(L_i/F_i\) of growing degree and bounded root discriminant.

  2. The relative norm-one unit group

    \[ E_i^1=\{u\in \mathcal O_{L_i}^{\times}:u\rho_i(u)=1\} \]

    has rank proportional to \([L_i:\mathbb Q]\).

  3. At a chosen complex embedding \(\sigma_i\), every \(u\in E_i^1\) satisfies

    \[ |\sigma_i(u)|=1. \]

    So these units become exact unit directions in the plane.

  4. Bounded regulator gives exponentially many such units whose other conjugates are uniformly bounded.
  5. If \(U_i\) is this set of unit directions, then for fixed \(k\), the sumset \(kU_i\) has size only \(C^{d_i}\). The reason is the norm-separation estimate: two distinct algebraic integers in \(kU_i\) have distinguished complex embeddings separated by at least \(C^{-d_i}\), while all lie in a bounded disk.

  6. A telescoping argument finds \(j\) such that

    \[ |jU_i| \]

    is not much larger than

    \[ |(j-1)U_i|. \]

  7. Taking

    \[ P_i=\sigma_i\bigl((j-1)U_i\cup jU_i\bigr) \]

    gives many unit distances, because every

    \[ a\in (j-1)U_i,\qquad u\in U_i \]

    yields

    \[ \sigma_i(a)\longleftrightarrow \sigma_i(a+u) \]

    at distance \(1\).

Thus the point sets \(P_i\subset \mathbb R^2\) satisfy

\[ u(P_i)\ge |P_i|^{1+\delta} \]

for some absolute \(\delta>0\), with \(|P_i|\to\infty\).

The previous proof had three places that needed real justification:

  1. Regulators. I asserted too quickly that bounded root discriminant gives exponentially bounded regulators. One needs a standard Landau–Stark residue bound plus the analytic class number formula, and then a separate comparison between the ordinary regulator and the relative norm-one regulator.
  2. Relative units. I used the fact that the relative norm-one unit group has rank proportional to the degree. This is true, but it needs a signature computation and a finite-index argument.
  3. Sumsets. Exact sumsets \(kU\) are not literally nested as sets. They are only nondecreasing in cardinality because \(1\in U\), via the injection \(x\mapsto x+1\). The proof below uses only cardinality monotonicity.

We now give the complete proof.

1. Arithmetic input

We use the following classical theorem of Martinet.

Martinet tower theorem. There exists an infinite sequence of totally real number fields

\[ F_1,F_2,\dots \]

with \([F_i:\mathbb Q]\to\infty\), and with uniformly bounded root discriminants:

\[ |\operatorname{Disc}(F_i)|^{1/[F_i:\mathbb Q]}\le \Delta_F \]

for some absolute constant \(\Delta_F\).

Fix such a tower. Choose a totally real base field \(F_0\) inside the tower, and choose an algebraic integer \(\theta\in \mathcal O_{F_0}\) with mixed signs at the real embeddings of \(F_0\): positive at at least one real embedding and negative at at least one real embedding. Such a \(\theta\) exists by weak approximation.

For each \(i\), set

\[ L_i:=F_i(\sqrt{\theta}). \]

Let

\[ d_i=[L_i:\mathbb Q]. \]

Since \(\theta\) is negative at some real embedding of \(F_i\), it is not a square in \(F_i\), so

\[ [L_i:F_i]=2. \]

Let \(\rho_i\) be the nontrivial \(F_i\)-automorphism of \(L_i\), so

\[ \rho_i(\sqrt{\theta})=-\sqrt{\theta}. \]

Because \(\theta\) has both positive and negative real signs, \(L_i\) has both real and complex places.

Choose one real embedding of \(F_0\) at which \(\theta<0\). For every \(i\), choose a complex embedding

\[ \sigma_i:L_i\hookrightarrow \mathbb C \]

lying over an extension of that real embedding. Then

\[ \sigma_i\circ \rho_i=\overline{\sigma_i}. \]

2. Bounded root discriminants and relative regulators

Let

\[ n_i=[F_i:\mathbb Q]. \]

Then

\[ d_i=2n_i. \]

The relative discriminant of \(L_i/F_i\) divides the extension of the fixed ideal \((4\theta)\subseteq \mathcal O_{F_0}\). Hence

\[ |\operatorname{Disc}(L_i)|^{1/d_i} \]

is uniformly bounded. Indeed,

\[ \operatorname{Disc}(L_i) = \operatorname{Disc}(F_i)^2 N_{F_i/\mathbb Q}(\mathfrak d_{L_i/F_i}), \]

and

\[ \mathfrak d_{L_i/F_i}\mid (4\theta)\mathcal O_{F_i}. \]

Therefore there is a constant \(\Delta_L\) such that

\[ |\operatorname{Disc}(L_i)|^{1/d_i}\le \Delta_L \]

for all \(i\).

We need the following standard consequence of the analytic class number formula.

Regulator bound. For every \(\Delta>0\), there exists \(C_\Delta>0\) such that if \(K\) is a number field of degree \(m\) and root discriminant at most \(\Delta\), then its ordinary regulator satisfies

\[ R_K\le C_\Delta^m. \]

Also, by Friedman’s lower bound for regulators, there exists \(c>0\) such that for every number field \(K\) of positive unit rank,

\[ R_K\ge c^{[K:\mathbb Q]}. \]

The upper bound follows from Landau’s residue estimate

\[ \operatorname{Res}_{s=1}\zeta_K(s) \le \left(C\frac{\log |\operatorname{Disc}(K)|}{[K:\mathbb Q]}\right)^{[K:\mathbb Q]} \]

and the analytic class number formula.

Now define the relative norm-one unit group

\[ E_i^1 := \{u\in \mathcal O_{L_i}^{\times}:u\rho_i(u)=1\}. \]

Let \(s_i\) be the number of real places of \(F_i\) at which \(\theta>0\). Since \(\theta\) is positive at a fixed positive proportion of the real embeddings coming from \(F_0\), there is a constant \(\kappa>0\) such that

\[ s_i\ge \kappa d_i. \]

At each such split real place \(v\), choose one of the two real embeddings

\[ \tau_v:L_i\hookrightarrow \mathbb R \]

above \(v\). Define

\[ \ell_i:E_i^1\to \mathbb R^{s_i} \]

by

\[ \ell_i(u)=\bigl(\log|\tau_v(u)|\bigr)_v. \]

The image \(\Lambda_i:=\ell_i(E_i^1)\) is a full-rank lattice in \(\mathbb R^{s_i}\). Its rank is \(s_i\). Indeed, \(L_i\) has signature

\[ (r_1,r_2)=(2s_i,n_i-s_i), \]

so

\[ \operatorname{rank}\mathcal O_{L_i}^{\times} = r_1+r_2-1 = n_i+s_i-1, \]

whereas

\[ \operatorname{rank}\mathcal O_{F_i}^{\times} = n_i-1. \]

The quotient of \(\mathcal O_{L_i}^{\times}\) by the subgroup generated by \(\mathcal O_{F_i}^{\times}\) and \(E_i^1\) is killed by \(2\), because for every unit \(u\),

\[ u^2 = N_{L_i/F_i}(u)\cdot \frac{u}{\rho_i(u)}, \]

with

\[ N_{L_i/F_i}(u)\in \mathcal O_{F_i}^{\times}, \qquad \frac{u}{\rho_i(u)}\in E_i^1. \]

Thus \(E_i^1\) has rank \(s_i\).

Let

\[ R_i^1:=\operatorname{covol}(\Lambda_i). \]

We claim that

\[ R_i^1\le R_0^{d_i} \]

for some constant \(R_0\) independent of \(i\).

To see this, compare the full logarithmic lattice of \(\mathcal O_{L_i}^{\times}\) with the direct sum of the logarithmic lattice of \(\mathcal O_{F_i}^{\times}\) and that of \(E_i^1\). In the full logarithmic embedding, the base-field units contribute vectors of the form \((x,x)\) at split real places, while norm-one units contribute vectors of the form \((y,-y)\). These subspaces are orthogonal. The finite-index argument above gives index at most \(2^{O(d_i)}\). Therefore

\[ R_i^1 \le C^{d_i}\frac{R_{L_i}}{R_{F_i}}. \]

Using the upper bound \(R_{L_i}\le C_1^{d_i}\) and the lower bound \(R_{F_i}\ge C_2^{-d_i}\), we obtain

\[ R_i^1\le R_0^{d_i}. \]

3. Many bounded norm-one units

Fix \(T>1\), to be chosen later. Consider the box

\[ [-T,T]^{s_i}\subset \mathbb R^{s_i}. \]

By Blichfeldt’s theorem, applied to the lattice \(\Lambda_i\), we have

\[ |\Lambda_i\cap [-T,T]^{s_i}| \ge \frac12\frac{T^{s_i}}{R_i^1} \]

for all sufficiently large \(i\). Hence

\[ |\Lambda_i\cap [-T,T]^{s_i}| \ge \frac12 \left(\frac{T^\kappa}{R_0}\right)^{d_i}. \]

Choose \(T\) large enough so that

\[ \frac{T^\kappa}{R_0}>4. \]

Then there exists \(\alpha>1\) such that, for all large \(i\),

\[ |\Lambda_i\cap [-T,T]^{s_i}| \ge \alpha^{d_i}. \]

Define

\[ U_i := \{u\in E_i^1:\|\ell_i(u)\|_\infty\le T\}. \]

Then

\[ |U_i|\ge \alpha^{d_i}. \]

Let

\[ M:=e^T. \]

For every \(u\in U_i\), we have

\[ |\sigma_i(u)|=1, \]

because

\[ \sigma_i(u)\overline{\sigma_i(u)} = \sigma_i(u)\sigma_i(\rho_i(u)) = \sigma_i(u\rho_i(u)) = 1. \]

Moreover, for every embedding \(\tau:L_i\hookrightarrow \mathbb C\),

\[ |\tau(u)|\le M. \]

Indeed, at split real places this follows from \(\|\ell_i(u)\|_\infty\le T\), and at complex places above negative real places the norm-one condition gives modulus \(1\).

Thus we have produced, for each large \(i\), a set \(U_i\) of algebraic units satisfying:

  1. \(|U_i|\ge \alpha^{d_i}\);
  2. \(|\sigma_i(u)|=1\) for all \(u\in U_i\);
  3. \(|\tau(u)|\le M\) for every embedding \(\tau\).

Also \(1\in U_i\).

4. A packing bound for sumsets

For a positive integer \(k\), define

\[ kU_i = \{u_1+\cdots+u_k:u_1,\dots,u_k\in U_i\}. \]

We prove:

Lemma. There is an absolute constant \(C_{\mathrm{pack}}\) such that, for all \(i\) and all \(k\ge 1\),

\[ |kU_i|\le (C_{\mathrm{pack}}kM)^{d_i}. \]

Proof. Let \(x,y\in kU_i\) be distinct. Then

\[ z:=x-y \]

is a nonzero algebraic integer. Therefore

\[ |N_{L_i/\mathbb Q}(z)|\ge 1. \]

Let

\[ r:=|\sigma_i(z)|. \]

The conjugate embedding \(\overline{\sigma_i}\) contributes the same absolute value \(r\). For every other embedding \(\tau\),

\[ |\tau(z)| \le |\tau(x)|+|\tau(y)| \le 2kM. \]

Thus

\[ 1 \le |N_{L_i/\mathbb Q}(z)| \le r^2(2kM)^{d_i-2}. \]

Hence

\[ r\ge (2kM)^{-(d_i-2)/2}. \]

So distinct points of \(\sigma_i(kU_i)\subset \mathbb C\) are separated by at least

\[ \rho:=(2kM)^{-(d_i-2)/2}. \]

On the other hand, since \(|\sigma_i(u)|=1\) for all \(u\in U_i\), every point of \(\sigma_i(kU_i)\) lies in the disk of radius \(k\). A planar packing bound gives

\[ |kU_i| = |\sigma_i(kU_i)| \le \left(\frac{5k}{\rho}\right)^2 \le (C_{\mathrm{pack}}kM)^{d_i} \]

for an absolute constant \(C_{\mathrm{pack}}\). ∎

5. Choosing a sumset with small growth

Fix a large integer \(K\), to be chosen momentarily, and set

\[ B:=C_{\mathrm{pack}}KM. \]

Then

\[ |KU_i|\le B^{d_i}. \]

Since

\[ |U_i|\ge \alpha^{d_i}, \]

we have

\[ \frac{|KU_i|}{|U_i|} \le \left(\frac{B}{\alpha}\right)^{d_i}. \]

Because \(1\in U_i\), the map

\[ x\mapsto x+1 \]

is an injection \(jU_i\hookrightarrow (j+1)U_i\). Hence the cardinalities \(|jU_i|\) are nondecreasing, and

\[ \prod_{j=2}^{K} \frac{|jU_i|}{|(j-1)U_i|} = \frac{|KU_i|}{|U_i|} \le \left(\frac{B}{\alpha}\right)^{d_i}. \]

Therefore there exists some \(j_i\in\{2,\dots,K\}\) such that

\[ \frac{|j_iU_i|}{|(j_i-1)U_i|} \le \exp(\varepsilon d_i), \]

where

\[ \varepsilon := \frac{\log(B/\alpha)}{K-1}. \]

Since

\[ B=C_{\mathrm{pack}}KM, \]

we have

\[ \varepsilon = \frac{\log K+O(1)}{K-1}\to 0 \]

as \(K\to\infty\). Choose \(K\) so large that

\[ \varepsilon<\frac12\log\alpha. \]

Define

\[ \lambda:=\log\alpha-\varepsilon>0. \]

6. Constructing the point set

For each sufficiently large \(i\), put

\[ A_i:=(j_i-1)U_i, \qquad B_i:=j_iU_i. \]

Define the point set

\[ P_i:=\sigma_i(A_i\cup B_i)\subset \mathbb C\cong \mathbb R^2. \]

Let

\[ n_i:=|P_i|. \]

We first bound \(n_i\). Since

\[ |B_i|\le e^{\varepsilon d_i}|A_i|, \]

we have

\[ n_i \le |A_i|+|B_i| \le 2e^{\varepsilon d_i}|A_i|. \]

Also, because \(j_i\le K\) and \(1\in U_i\), both \(|A_i|\) and \(|B_i|\) are at most \(|KU_i|\). Indeed, one pads sums with copies of \(1\). Therefore

\[ n_i \le 2|KU_i| \le 2B^{d_i}. \]

Now count unit distances. For every pair

\[ (a,u)\in A_i\times U_i, \]

we have

\[ a+u\in B_i. \]

Therefore both

\[ \sigma_i(a) \quad\text{and}\quad \sigma_i(a+u) \]

belong to \(P_i\), and

\[ |\sigma_i(a+u)-\sigma_i(a)| = |\sigma_i(u)| = 1. \]

The map

\[ (a,u) \mapsto \bigl(\sigma_i(a),\sigma_i(a+u)\bigr) \]

is injective. Indeed, if two such ordered pairs coincide, then \(\sigma_i(a)=\sigma_i(a')\), hence \(a=a'\), and then \(\sigma_i(u)=\sigma_i(u')\), hence \(u=u'\).

Thus we obtain at least \(|A_i||U_i|\) ordered unit-distance pairs. Therefore

\[ u(P_i) \ge \frac12 |A_i||U_i|. \]

Using

\[ |U_i|\ge \alpha^{d_i} \]

and

\[ |A_i| \ge \frac{n_i}{2e^{\varepsilon d_i}}, \]

we get

\[ u(P_i) \ge \frac14 n_i e^{-\varepsilon d_i}\alpha^{d_i} = \frac14 n_i e^{\lambda d_i}. \]

Since

\[ n_i\le 2B^{d_i}, \]

we have

\[ e^{\lambda d_i} \ge \left(\frac{n_i}{2}\right)^{\lambda/\log B}. \]

Hence

\[ u(P_i) \ge c\, n_i^{1+\delta_0}, \]

where

\[ \delta_0:=\frac{\lambda}{\log B}>0 \]

and \(c>0\) is an absolute constant.

Finally, since \(1\in U_i\), we have

\[ |A_i|\ge |U_i|\ge \alpha^{d_i}, \]

so

\[ n_i\to\infty. \]

Discarding finitely many initial terms, we may absorb the constant \(c\) into the exponent. Namely, for all sufficiently large \(i\),

\[ c\, n_i^{1+\delta_0} \ge n_i^{1+\delta_0/2}. \]

Set

\[ \delta:=\frac{\delta_0}{2}>0. \]

Then, after relabeling the remaining infinite sequence,

\[ u(P_i)\ge |P_i|^{1+\delta} \]

for all \(i\), with \(|P_i|\to\infty\).

This proves the theorem. ∎
